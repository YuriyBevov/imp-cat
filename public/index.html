Рабочее поле

Крупная линия — 16 px. Исходная геометрия сохраняется без округления; настройка применяется только при ручном перемещении.

Масштаб просмотра 100%

После загрузки документ вписывается в рабочую область. Cmd/Ctrl + колесо меняет зум под курсором и не влияет на экспорт.

Добавляет реальное свободное место снизу страницы. При экспорте увеличенное поле делится на обычные страницы Word.

Команда сдвигает пересекающиеся сегменты только вниз и при необходимости расширяет поле. Исходное положение можно вернуть через меню сегмента.

Групповое перемещение: протяните рамку левой кнопкой мыши по свободной области, затем перетащите ⠿ у любого выбранного сегмента.

Отмена: нажимайте Cmd/Ctrl + Z, чтобы пошагово отменять изменения документа.
