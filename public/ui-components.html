Тултип BaseTooltip
Согласовано

Общая текстовая подсказка для кнопок с иконками. Текст берётся из доступного названия `aria-label`, всегда начинается с заглавной буквы; тултип показывается при наведении и клавиатурном фокусе, а также работает с динамически добавленными кнопками. Компонент выбирает свободную сторону кнопки и остаётся внутри видимой области экрана.

Скроллбар BaseScrollbar
Согласовано

Общий тонкий скроллбар по образцу briefing-app: прозрачная дорожка, контрастный скруглённый ползунок и усиление цвета при наведении. Автоматически применяется ко всем прокручиваемым областям проекта.

Прокручиваемая область

Этот пример использует те же глобальные стили, что холст, инспектор, списки документов, модальные окна и страницы документации.

Прокрутите содержимое вниз, чтобы проверить дорожку и ползунок.

Навигация инспектора InspectorNavigation
Согласовано

Постоянная вертикальная рейка из пяти иконных кнопок. Панель сохраняет ширину и плавно выезжает без перестроения содержимого; повторное нажатие активной кнопки скрывает её. Все разделы доступны всегда, а зависящие от выбора показывают информационную заметку вместо инструментов, пока сегмент не выбран.

Выбор цвета ColorPicker
Согласовано

Компактный контрол цвета текста. Внешний вид задаёт общий компонент, а системная палитра открывается через нативный безопасный input.

Размер шрифта, px NumberStepper
Согласовано

Компактный пошаговый контрол без выпадающего списка. Кнопки меняют значение на единицу в диапазоне 10–80.

Выпадающий список BaseSelect
Согласовано

Единый кастомный список с собственным trigger, плавающим меню, выбранным состоянием и клавиатурным управлением.

Флажок выбора BaseCheckbox
Согласовано

Кастомный флажок с устойчивой отрисовкой при масштабировании интерфейса. Нативный input остаётся доступным для клавиатуры и скринридера.

Иконки IconButton / BaseIcon

Единый локальный SVG-спрайт. Все кнопки только с иконкой используют `.icon-button`; размеры, цвет, заливка и рамка меняются абстрактными модификаторами `.icon-button--*`. Контекстные классы не дублируют оформление компонента.
