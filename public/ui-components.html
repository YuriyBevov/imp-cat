UI-компоненты

Каталог согласованных элементов интерфейса ICAT. Новые компоненты добавляются сюда по мере утверждения внешнего вида и поведения.

Просмотр оригинала SourcePreviewControls
Согласовано

Плавающая группа управления масштабом оригинала. Располагается в правом нижнем углу области просмотра и не занимает место документа.

Выбор цвета ColorPicker
Согласовано

Компактный контрол цвета текста. Внешний вид задаёт общий компонент, а системная палитра открывается через нативный безопасный input.

Размер шрифта, px NumberStepper
Согласовано

Компактный пошаговый контрол без выпадающего списка. Кнопки меняют значение на единицу в диапазоне 10–80.

Выпадающий список BaseSelect
Согласовано

Единый кастомный список с собственным trigger, плавающим меню, выбранным состоянием и клавиатурным управлением.

Флажок выбора BaseCheckbox
Согласовано

Кастомный флажок с устойчивой отрисовкой при масштабировании интерфейса. Нативный input остаётся доступным для клавиатуры и скринридера.

Иконки IconButton / BaseIcon

Единый локальный SVG-спрайт. Все кнопки только с иконкой используют `.icon-button`; размеры, цвет, заливка и рамка меняются абстрактными модификаторами `.icon-button--*`. Контекстные классы не дублируют оформление компонента.
