UI-компоненты

Каталог согласованных элементов интерфейса ICAT. Новые компоненты добавляются сюда по мере утверждения внешнего вида и поведения.

Видимость типов сегментовSegmentTypeLabelsToggle
Согласовано

Иконная кнопка этапа «Макет» скрывает служебные подписи типов сегментов и повторным нажатием возвращает их. Иконка и адаптивный тултип всегда обозначают следующее доступное действие.

Управление ориентацией страницPageOrientationControls
Согласовано

Иконные команды поворачивают одну страницу или весь документ влево и вправо с шагом 90°, а также сбрасывают поворот. Назначение каждой команды показывает общий адаптивный тултип.

Действия Базы знаний в сегментеSegmentKnowledgeActions
Согласовано

На этапе «Сегменты» весь блок открывает точные совпадения и добавляет пару непосредственно из служебной строки поля перевода. Иконки используют общий компонент кнопки и адаптивные тултипы.

Точное совпадение — выделяется только фактическое вхождение записи в этой колонке.

Тултип BaseTooltip
Согласовано

Общая текстовая подсказка для кнопок с иконками. Текст берётся из доступного названия `aria-label`, всегда начинается с заглавной буквы; тултип показывается при наведении и клавиатурном фокусе, а также работает с динамически добавленными кнопками. Компонент выбирает свободную сторону кнопки и остаётся внутри видимой области экрана.

Скроллбар BaseScrollbar
Согласовано

Общий тонкий скроллбар по образцу briefing-app: прозрачная дорожка, контрастный скруглённый ползунок и усиление цвета при наведении. Автоматически применяется ко всем прокручиваемым областям проекта.

Флажок выбора BaseCheckbox
Согласовано

Иконки IconButton / BaseIcon

Единый локальный SVG-спрайт. Все кнопки только с иконкой используют `.icon-button`; размеры, цвет, заливка и рамка меняются абстрактными модификаторами `.icon-button--*`. Контекстные классы не дублируют оформление компонента.
