# Руководство пользователя ICAT Translation Studio

## 1. Назначение приложения

ICAT Translation Studio — рабочее место бюро переводов для распознавания, перевода, редактирования и сборки документов. В текущей версии можно:

- загрузить PDF, скан или изображение;
- распознать содержимое документа с помощью выбранной AI-модели;
- получить текстовые сегменты с координатами и типами объектов;
- сопоставить исходник и перевод в двух колонках;
- использовать переводческую Базу знаний;
- перевести отдельные сегменты, выбранную группу или весь документ;
- уточнить перевод для AI общим или посегментным комментарием;
- вручную исправить текст, типографику и расположение объектов;
- проверить документ и скачать результат в DOCX или PDF.

Поддерживаемые входные форматы: PDF, PNG, JPG/JPEG, WebP, TIFF, HEIC и BMP. Поддерживаемые форматы выгрузки: DOCX и PDF.

## 2. Рекомендуемый порядок работы

1. Откройте ICAT в браузере.
2. В разделе «AI-провайдер» выберите AITunnel или Codex и проверьте подключение.
3. Загрузите один или несколько документов.
4. Дождитесь окончания распознавания. Не закрывайте вкладку, если хотите видеть текущий прогресс; само задание продолжает работать на сервере.
5. Сравните распознанный макет с оригиналом слева.
6. Исправьте пропущенный или неверно распознанный текст и типы специальных объектов.
7. Выберите языки исходника и перевода.
8. Перейдите в режим «Сегменты» и отметьте необходимые строки.
9. Запустите перевод выбранных сегментов или всего документа.
10. Проверьте предложения Базы знаний и варианты AI.
11. При необходимости добавьте комментарий для AI и повторно исправьте перевод.
12. Отредактируйте расположение, размеры и оформление сегментов.
13. Запустите сравнение макета с оригиналом и финальную проверку.
14. Скачайте DOCX или PDF.

## 3. Верхняя панель

Кнопка с тремя горизонтальными линиями в правой части верхней панели открывает меню действий. Меню закрывается после выбора команды, клика вне него или нажатия `Esc`.

| Кнопка | Что делает |
| --- | --- |
| **Документы** | Открывает список всех рабочих и архивных документов. |
| **База знаний** | Открывает общий справочник утверждённых пар «исходный текст → перевод». |
| **AI-инструкции** | Открывает отдельное окно управления готовыми правилами перевода. Оно доступно даже без открытого документа. |
| **AI-провайдер** | Открывает выбор маршрута AI, модели и настройку ключа AITunnel. |
| **Документация** | Открывает в новой вкладке актуальные технические требования, архитектуру и критерии приёмки. |
| **Руководство** | Открывает в новой вкладке настоящее пользовательское руководство. |
| **Компоненты** | Открывает каталог согласованных UI-компонентов и используемых SVG-иконок. |
| **Отменить** | Отменяет последнее редактирующее действие. Аналог `Ctrl/Cmd + Z`. |
| **Повторить** | Возвращает отменённое действие. Аналог `Ctrl/Cmd + Shift + Z`. |
| **Другой документ** | Сохраняет текущую сцену и открывает выбор новых файлов. |
| **Скачать DOCX** | Собирает текущую утверждённую сцену в документ Microsoft Word. |
| **Скачать PDF** | Собирает текущую утверждённую сцену в PDF. |

Страницы справки формируются непосредственно из актуальных Markdown-файлов проекта. После обновления руководства или технической документации достаточно перезагрузить соответствующую страницу браузера.

Все пиктограммы интерфейса берутся из локального SVG-набора и сопровождаются текстовой подсказкой или доступным названием. Страница «Компоненты» служит эталоном для уже согласованных элементов; первым в ней зафиксирован блок `SourcePreviewControls`.

## 4. Загрузка и обработка

| Элемент | Что делает |
| --- | --- |
| **Выбрать документы** | Открывает системный выбор файлов. Можно выбрать несколько документов. |
| Область загрузки | Принимает файлы перетаскиванием мышью. |
| Вкладка документа | Переключает текущий рабочий документ. Цветная точка показывает состояние обработки. |
| Кнопка с иконкой закрытия во вкладке | Закрывает вкладку в интерфейсе, но не удаляет сохранённый документ. |

Открытые вкладки собраны у правого края строки документов. Если вкладок больше доступной ширины, список прокручивается по горизонтали.
| **Отменить обработку** | Прерывает выполняющееся AI-задание. Уже сохранённый исходник остаётся на сервере. |
| **Повторить обработку** | Повторно запускает завершившееся с ошибкой или отменённое задание без новой загрузки файла. |

Большие документы делятся сервером на пакеты страниц. Интерфейс показывает общий процент, номер текущего пакета, количество обработанных страниц и найденных сегментов.

## 5. Оригинал документа

Оригинал находится слева от редактируемой области и не меняется при редактировании.

Кнопки масштаба находятся поверх оригинала в правом нижнем углу области просмотра.

Слева от оригинала расположена компактная панель страниц шириной 60 пикселей. Каждая миниатюра содержит изображение страницы и её номер снизу; нажатие переводит оригинал и рабочий макет к выбранной странице.

| Кнопка | Что делает |
| --- | --- |
| **−** | Уменьшает оригинал. |
| **+** | Увеличивает оригинал. |
| **100%** | Показывает оригинал в масштабе 1:1. |
| Кнопка с иконкой рамки | Вписывает оригинал по ширине доступной панели. |
| Кнопка с иконкой листа-макета | Сворачивает или возвращает оригинал, освобождая место для редактора. Активный вид кнопки означает, что оригинал показан; подсказка сообщает текущее действие. |
| Перетаскивание страницы левой кнопкой мыши | Перемещает увеличенный оригинал по горизонтали и вертикали внутри области просмотра. |

`Ctrl/Cmd + колесо мыши` над оригиналом изменяет его масштаб независимо от рабочего документа.

## 6. Режимы рабочей области

Общая панель инструментов располагается сразу под вкладками документов и занимает всю ширину редактора. Группы контролов прижаты к правому краю и управляют видом макета, масштабом, сеткой и форматированием независимо от ширины отдельных боковых панелей.

Кнопка показа оригинала стоит первой слева в группе режимов, перед переключателями «Макет» и «Сегменты».

| Кнопка | Что делает |
| --- | --- |
| Кнопка с иконкой сетки | Включает «Макет»: показывает сегменты на страницах в распознанных координатах. Используется для верстки. |
| Кнопка с иконкой строк-карточек | Включает «Сегменты»: показывает исходник слева и перевод справа в порядке чтения документа. Используется для перевода и проверки. |
| **− / +** | Уменьшает или увеличивает редактируемый документ. |
| Кнопка с двумя разнонаправленными стрелками | Вписывает рабочий документ по доступной ширине. |
| **100%** | Возвращает редактируемый документ к фактическому масштабу 100%. |

`Ctrl/Cmd + колесо мыши` меняет масштаб относительно позиции курсора. Масштаб влияет только на отображение и не меняет координаты экспорта.

### Добавление и удаление страниц

Под каждым листом находятся две команды:

| Кнопка | Что делает |
| --- | --- |
| **Добавить пустую страницу ниже** | Вставляет новый лист того же формата сразу после выбранной страницы. Исходные изображения следующих страниц сохраняют правильную привязку. |
| **Удалить пустую страницу** | Удаляет лист, только если на нём нет включённых в документ сегментов. В документе всегда остаётся хотя бы одна страница. |

У добавленной страницы нет изображения оригинала: слева отображается нейтральная пустая страница. Такой лист полноценно участвует в редактировании и экспорте.

## 7. Выбор и перемещение сегментов

- Обычный клик выбирает один сегмент.
- `Ctrl/Cmd + клик` добавляет сегмент к текущему выделению или исключает его из выделения.
- Протягивание рамки по свободной области выделяет все пересекающиеся сегменты.
- Перетаскивание выбранного сегмента перемещает всю выделенную группу.
- Во время переноса сегмент свободно следует за курсором и не застревает у границы исходного листа. Целевая страница подсвечивается; после отпускания сегмент переносится в её систему координат и привязывается к сетке. Отпускание в промежутке между листами выбирает ближайшую страницу.
- Выделение не добавляет сегменту отдельную обводку: состояние обозначают только маркеры перемещения и изменения размера, чтобы рамка не мешала точной визуальной расстановке.
- Маркер перемещения всегда находится снаружи слева от сегмента, в том числе у левого края страницы. Он не перекрывает текст и может выходить за границу листа.
- Синий маркер в правом нижнем углу изменяет размер сегмента. Он всегда находится снаружи рамки, в том числе у правого и нижнего края страницы, поэтому не перекрывает содержимое.
- Размер фиксируется при отпускании кнопки мыши, в том числе если браузер завершил захват указателя вне самого маркера. `Esc` по-прежнему отменяет незавершённое изменение.
- Поля `X`, `Y`, «Ширина» и «Высота» позволяют задать точные значения.
- Нажатие `Esc` отменяет незавершённое перетаскивание или изменение размера, снимает выделение, закрывает открытые окна и убирает фокус.

### Сетка

| Элемент | Что делает |
| --- | --- |
| Список с иконкой сетки | Контрол шириной 72 px выбирает плотность квадратной сетки: `XS`, `SM`, `MD`, `LG`, `XL` или `XXL`. Между контролом и разделителем оставлен внутренний отступ. `XS` даёт самую мелкую сетку, `XXL` — самую крупную. Все перемещаемые сегменты всегда привязаны к выбранной сетке. |

Размер квадратов рассчитывается относительно ширины рабочей области каждой страницы, поэтому интерфейс не требует подбирать пиксели для документов разного формата. По горизонтали рабочая область всегда делится на целое число одинаковых квадратов; вертикальные и горизонтальные линии начинаются от одного левого верхнего угла. Если высота не делится на целый квадрат, нижняя граница остаётся отдельной доступной линией привязки. Сетка влияет только на координаты расстановки. Она не округляет ширину или высоту сегмента и не изменяет результат команд подгонки по содержимому.

Во время перетаскивания сегмент движется свободно. После отпускания мыши его левый верхний угол подтягивается к ближайшему пересечению сетки. Возле правой и нижней границ выбирается последняя доступная ячейка, на которой весь сегмент остаётся внутри рабочей области; его размеры при этом не меняются.

Зелёная рамка теперь обозначает **рабочую область документа**, а не границы найденного текста. Она рассчитывается одинаково для страниц одного формата и оставляет симметричные поля по всем сторонам. Перетащить сегмент в поля нельзя. При экспорте эти зоны сохраняются как поля DOCX/PDF; уже распознанный исходный объект, который изначально находился в поле, остаётся видимым и отмечается финальной проверкой до первого ручного перемещения.

## 8. Форматирование текста

Если внутри сегмента выделен фрагмент текста, шрифт, цвет, жирность, курсив и размер применяются только к этому фрагменту. Без текстового выделения форматирование применяется ко всем выбранным сегментам. Чекбокс **«Применить ко всем сегментам»** переключает область действия всей панели форматирования с выделения на все активные текстовые сегменты документа.

Список шрифтов содержит `Arial`, `Aptos`, `Calibri`, `Cambria`, `Times New Roman`, `Georgia`, `Verdana`, `Tahoma` и `Courier New`. Цвет выбирается компактной цветовой кнопкой. Word сохраняет название выбранного семейства, но на компьютере получателя этот шрифт должен быть установлен или доступен как облачный шрифт Office; иначе Word выполнит подстановку, способную изменить переносы строк. Для наиболее переносимого результата рекомендуется Arial или Times New Roman.

| Кнопка или поле | Что делает |
| --- | --- |
| **B** | Включает или выключает полужирное начертание. |
| **I** | Включает или выключает курсив. |
| **⇤** | Выравнивает текст по левому краю. |
| **≡** | Центрирует текст внутри сегмента. |
| **⇥** | Выравнивает текст по правому краю. |
| **☰** | Выравнивает текст по ширине. |
| **− / размер / px / +** | Уменьшает или увеличивает размер выделенного текста либо выбранных сегментов с шагом 1 px. Значение от 10 до 80 можно также ввести непосредственно в поле; пустое поле означает, что у выбранных элементов разные размеры. |
| **Применить ко всем сегментам** | Распространяет размер, жирность, курсив или выбранное выравнивание сразу на все активные текстовые сегменты. Внутренние индивидуальные значения соответствующего свойства заменяются общим. |

В инспекторе также доступны поля «Шрифт, px» и «Интервал» для точной настройки выбранного сегмента.

После изменения текста, перевода, размера шрифта, интервала, жирности, курсива или выравнивания рамка сегмента автоматически пересчитывается по содержимому. Сначала она растёт по ширине без лишнего переноса строки. Если строка физически шире листа, ширина ограничивается размером страницы, и только тогда текст переносится на следующие строки. Автоподстройка не изменяет размеры остальных сегментов.

## 9. Агент-переводчик

| Кнопка | Что делает |
| --- | --- |
| **Выбрать все переводимые сегменты** | Отмечает или снимает отметку со всех строк для массового перевода. |
| **Проверить структуру** | Локально проверяет порядок чтения, типы объектов и структуру текущей сцены. Не выполняет повторное распознавание исходника. |
| **Повторить анализ исходника** | Повторно отправляет сохранённые страницы выбранному AI-провайдеру и заменяет сцену новым результатом. Ручные изменения нужно предварительно оценить, поскольку сцена перестраивается. |
| **Перевести выбранные** | Переводит отмеченные сегменты. Если отмечены все, надпись меняется на «Перевести весь документ». |
| **Исправить наложения** | Выполняет детерминированное разнесение пересекающихся блоков без обращения к AI. |
| **AI: сравнить и исправить макет** | Рендерит текущий макет, сравнивает его с оригиналом выбранной моделью и применяет уверенные исправления геометрии. |
| **Отменить сравнение** | Прерывает выполняющееся AI-сравнение макета. |
| **Финальная проверка** | Ищет непереведённые, сомнительные, выходящие за страницу и пересекающиеся сегменты. |

Машинный перевод всегда требует проверки переводчиком.

## 10. Комментарии и готовые инструкции для AI

### Общий комментарий

Поле «Общий комментарий для ИИ» задаёт правило для выбранных сегментов или всего документа. Примеры:

- `Все имена передавай транслитерацией.`
- `Сохраняй номера и даты без изменений.`
- `Все печати не включай в финальную сборку.`

| Кнопка | Что делает |
| --- | --- |
| **Добавить** | Добавляет выбранную готовую инструкцию в общий комментарий. Уже добавленный одинаковый текст не дублируется. |
| **Сохранить текущую** | По явному действию сохраняет текущий комментарий в общий набор шаблонов. |
| **Редактировать** | Открывает текст выбранной готовой инструкции для изменения. |
| **Сохранить изменения** | Сохраняет новый текст шаблона на сервере. |
| **Отмена** | Закрывает редактор шаблона без сохранения. |
| **Удалить из набора** | Удаляет выбранный шаблон после подтверждения. Уже применённые к документам комментарии не изменяются. |
| **Исправить выбранные** | Повторно отправляет отмеченные переводы AI с учётом общего и локальных комментариев. |
| **Исправить весь документ** | Повторно обрабатывает все уже переведённые сегменты документа. |

Набор готовых инструкций хранится на сервере и доступен в других документах. Одинаковые инструкции повторно не создаются.

### Отдельное окно «AI-инструкции»

Окно открывается одноимённой кнопкой в верхней панели и позволяет управлять всем набором независимо от документа.

| Кнопка или поле | Что делает |
| --- | --- |
| Поиск | Фильтрует список по полному тексту инструкции. |
| **＋ Новая инструкция** | Открывает пустую форму создания шаблона. |
| **Изменить** | Открывает выбранную инструкцию и позволяет изменить её текст. |
| **Сохранить инструкцию** | Создаёт новый шаблон или сохраняет изменения существующего. |
| **Отмена** | Закрывает форму без сохранения. |
| **Удалить** | Удаляет шаблон после подтверждения. Комментарии, ранее скопированные в документы, не изменяются. |
| **×** | Закрывает окно управления инструкциями. |

### Комментарий отдельного сегмента

В правой колонке режима «Сегменты» находятся:

| Кнопка | Что делает |
| --- | --- |
| **Добавить** | Добавляет выбранный готовый шаблон к комментарию конкретного сегмента. |
| **Сохранить** | Сохраняет локальный комментарий как новый готовый шаблон. |
| **Исправить ИИ** | Исправляет только этот перевод. Локальный комментарий имеет приоритет над общим. |

Если AI по явной инструкции пометил объект как исключённый, объект сохраняется в проекте, но не попадает в DOCX/PDF. Такое действие можно отменить через историю.

## 11. Инспектор выбранного сегмента

| Элемент | Назначение |
| --- | --- |
| **Тип содержимого** | Меняет тип объекта: текст, таблица, ячейка, штамп, печать, подпись, рукописный текст, логотип, изображение или неопределённый объект. |
| **ID таблицы / строка / колонка / размеры объединения** | Задаёт структурную позицию ячейки в настоящей табличной модели. |
| **Распознанный исходник** | Позволяет исправить результат распознавания. |
| **Уверенность распознавания** | Показывает оценку модели. Низкое значение требует ручной проверки по оригиналу. |
| **Перевод / обозначение** | Содержит выбранный перевод или служебное обозначение объекта. |
| **X / Y / Ширина / Высота** | Управляет точной геометрией объекта на странице. |

Формат специальных объектов при переводе:

- печать — `/Печать: распознанный текст/`;
- штамп — `/Штамп: распознанный текст/`;
- подпись — `/Подпись/`.

## 12. Части сегмента и отдельные термины

Внутренние части позволяют отдельно перевести слово или фразу, не создавая новый прямоугольник на странице.

| Кнопка | Что делает |
| --- | --- |
| **Разбить по предложениям** | Создаёт несколько внутренних переводческих единиц внутри одного внешнего сегмента. |
| **Вынести выделенное в отдельную часть** | Делает выделенное в поле исходника слово или фразу самостоятельной внутренней единицей. |
| **Объединить внутри** | Снова соединяет внутренние единицы, не меняя геометрию внешнего блока. |
| **Применить все 100% совпадения** | Подставляет все точные предложения Базы знаний во внутренние единицы выбранного сегмента. |
| **Сохранить эту пару в БЗ** | Сохраняет конкретную внутреннюю пару «исходник → перевод». |
| **Применить 100% совпадение** | Применяет найденный точный перевод только к соответствующей части. |

Если разбиение выполняется после ввода переводов, приложение предупреждает о возможной очистке несопоставленных частей.

## 13. Размеры и расположение

### Подгонка по содержимому

| Кнопка | Что делает |
| --- | --- |
| **Ширина по тексту** | Подбирает ширину выбранных сегментов по содержимому. |
| **Высота по тексту** | Подбирает высоту выбранных сегментов по содержимому. |
| **Оба размера** | Измеряет только содержимое сегмента, затем одновременно подбирает ширину и высоту. Если результат не помещается у правого или нижнего края, блок сдвигается внутрь страницы без обрезания рассчитанного размера. Для одинакового текста и оформления помогает получить одинаковые размеры блоков. |

Перетаскивание изменяет только координаты выбранных сегментов. Оно не пересчитывает размеры перемещаемого или соседних блоков. Повторная подгонка одного сегмента также не изменяет размеры ранее нормализованных сегментов.

Высота сегмента не может быть меньше высоты его содержимого. При уменьшении ширины перенос строк пересчитывается, и минимальная высота увеличивается автоматически; ручка размера и поле «Высота» не позволяют обрезать текст.

### Выравнивание выбранных относительно друг друга

Работает только для сегментов одной страницы.

| Кнопка | Что делает |
| --- | --- |
| **Лево / Центр X / Право** | Выравнивает выбранные блоки по горизонтальной стороне или оси общей группы. |
| **Верх / Центр Y / Низ** | Выравнивает выбранные блоки по вертикальной стороне или оси общей группы. |
| **↔ Равные интервалы** | Равномерно распределяет минимум три сегмента по горизонтали. |
| **↕ Равные интервалы** | Равномерно распределяет минимум три сегмента по вертикали. |

### Выравнивание относительно документа

Сначала выберите «рабочую область документа» или «лист с учётом полей». В обоих режимах защитные поля остаются недоступными для размещения; затем кнопки «Лево», «Центр X», «Право», «Верх», «Центр Y» и «Низ» перемещают всю выбранную группу относительно допустимой области.

### Расстановка

Расстановка работает подобно CSS Flexbox:

- «Направление» выбирает горизонтальный ряд или вертикальную колонку;
- «Контейнер» выбирает границы выделения либо рабочую область листа с защитными полями;
- «Главная ось» задаёт начало, центр, конец или один из вариантов распределения свободного пространства;
- «Поперечная ось» задаёт начало, центр, конец, растягивание или базовую линию;
- «Интервал» задаёт минимальный промежуток в пикселях;
- **Применить расстановку** выполняет выбранную схему.

База знаний хранит утверждённые переводы и глоссарии. Записи сохраняются в нижнем регистре, а при применении регистр автоматически адаптируется к исходнику: нижний, первая заглавная или полностью прописной.

### В инспекторе

| Кнопка или поле | Что делает |

| **Открыть БЗ** | Открывает общий редактор записей. |

## 16. Финальная проверка

Панель проверки показывает количество ошибок, предупреждений и готовых переводов. Проверяются:

- отсутствующие переводы;
- низкая уверенность распознавания;
- выход за границы страницы;
- размещение в защитных полях вне рабочей области;
- переполнение текстом;
- пересечения сегментов;
- исключённые или сомнительные объекты.

Нажатие на предупреждение выбирает связанные сегменты и переносит редактор к их странице. Кнопка **×** закрывает панель.

## 18. Настройка AI-провайдера

| Кнопка или поле | Что делает |
| --- | --- |
| **Провайдер** | Выбирает единый AI-маршрут: AITunnel или Codex. Распознавание, повторный анализ, перевод и AI-проверка идут по выбранному маршруту. |
| **Модель AITunnel** | Выбирает доступную модель. Для анализа документов нужна модель с поддержкой изображений. |
| **API-ключ AITunnel** | Принимает ключ провайдера. Сохранённое значение обратно в браузер не возвращается. |
| **Сохранить ключ на сервере после перезапуска** | Разрешает записать ключ в серверный `.env`, исключённый из Git. |
| **Проверить подключение** | Проверяет ключ, каталог и доступность выбранной модели без запуска полного анализа документа. |
| **Сохранить** | Сохраняет выбранный маршрут и модель; при явной настройке сохраняет ключ. |
| **Удалить ключ** | Удаляет ключ из памяти процесса и серверного `.env`. |
| **×** | Закрывает настройки. |

Ключ передаётся из браузера на backend в RSA-OAEP-шифротексте. Backend обращается к AITunnel только по HTTPS. Сами изображения документа при AI-анализе отправляются выбранному внешнему провайдеру.

## 19. Сохранение данных

- Сцена документа автоматически сохраняется после редактирования.
- Готовые документы восстанавливаются после перезагрузки страницы.
- Незавершённые задания сохраняются и возобновляются после перезапуска backend.
- База знаний хранится в PostgreSQL/pgvector, если задан `DATABASE_URL`.
- Готовые AI-инструкции хранятся на сервере в `data/studio/translation-instructions.json`.
- Для production каталогу `data/studio` и PostgreSQL требуется постоянное хранилище и резервное копирование.

## 21. Важные ограничения

- AI может ошибаться в тексте, типе объекта и переводе. Для юридических документов обязательна проверка человеком.
- Повторный анализ исходника перестраивает сцену и может заменить ручные изменения.
- Не все сложные изображения и графические объекты пока воспроизводятся в DOCX с полной визуальной точностью.
- Низкоуверенные рекомендации AI по верстке не следует принимать без сравнения с оригиналом.
- Авторизация пользователей и разделение данных между организациями относятся к следующему production-этапу.
