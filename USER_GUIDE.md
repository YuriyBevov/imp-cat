# Руководство пользователя ICAT Translation Studio

## 1. Назначение приложения

ICAT Translation Studio — рабочее место бюро переводов для распознавания, перевода, редактирования и сборки документов. В текущей версии можно:

- загрузить PDF, скан или изображение;
- распознать содержимое документа с помощью выбранной AI-модели;
- получить текстовые сегменты с координатами и типами объектов;
- сопоставить исходник и перевод в двух колонках;
- использовать переводческую Базу знаний;
- перевести отдельные сегменты, выбранную группу или весь документ;
- уточнить перевод для AI общим или посегментным комментарием;
- вручную исправить текст, типографику и расположение объектов;
- проверить документ и скачать результат в DOCX или PDF.

Поддерживаемые входные форматы: PDF, PNG, JPG/JPEG, WebP, TIFF, HEIC и BMP. Поддерживаемые форматы выгрузки: DOCX и PDF.

### Защита данных перед отправкой в ИИ

По умолчанию включён обязательный локальный этап обезличивания. Загруженный оригинал остаётся на сервере ICAT; если приложение запущено на вашем компьютере, обработка происходит на нём. До проверки очищенных страниц документ не отправляется AI-провайдеру. В защищённом режиме доступен **AITunnel**; Codex с файловыми инструментами заблокирован. Проверка ключа запрашивает только каталог моделей.

1. Загрузите PDF или изображение. Для DOCX сначала сохраните PDF локально: прямой импорт DOCX ещё не реализован.
2. Проверьте ориентацию, выберите язык исходника и нажмите **«Подготовить обезличенную копию»**. Tesseract, локальная NER-модель и правила ищут имена, организации, адреса, контакты, даты и идентификаторы. Облачная модель на этом этапе не используется.
3. На экране **«Проверьте обезличивание»** сравните **каждую** очищенную страницу с оригиналом через **«Показать оригинал»**. Автоматическое обнаружение может пропускать данные. Проверьте также подписи, фотографии, печати, рукописные записи и QR-коды.
4. Пропущенные текстовые значения добавьте в **«Дополнительно скрыть»**, по одному в строке. Для графики включите **«Рисовать дополнительные маски»** и выделите область либо введите координаты в пикселях подготовленной страницы (номер страницы начинается с 1). Рамка — будущая маска: нажмите **«Обновить очищенную копию»**, чтобы физически удалить её содержимое, и проверьте результат снова. Если OCR не прочитал страницу, подтверждение требует ручную маску на всю страницу. Если обозначение не поместилось в маску, расширьте область.
5. Поле **«Публичные значения, которые можно оставить»** позволяет снять избыточные автоматические маски для проверенных публичных сведений. Явно заданные дополнительные маски имеют приоритет. В списке найденных значений исправьте OCR или задайте утверждённое написание для локальной подстановки при выгрузке. Эти значения не отправляются в ИИ.
6. Отметьте **«Я проверил все страницы и значения для восстановления»**, затем **«Подтвердить и начать распознавание»**. AI получает только проверенные очищенные изображения, с условными обозначениями `ICATPII_…`. Потеря или неизвестное обозначение блокирует применение распознавания; перевод и AI-правки также проверяют сохранение обозначений.
7. Если новые правки, комментарии или инструкции требуют отправки новых текстов, откроется **«Проверьте новые данные для ИИ»**. Просмотрите локально очищенный текст, при необходимости примените дополнительные маски, затем подтвердите отправку. Изменившийся документ или запрос требует новой проверки.
8. При скачивании DOCX/PDF флажок **«Восстановить скрытые значения локально»** включён по умолчанию. Снимите его для обезличенного результата. Рабочая сцена сохраняет обозначения; реальные значения подставляются только в локальную копию экспорта. Восстановленный файл проверьте по оригиналу: он может содержать ошибки OCR. Восстановление графических подписей, фотографий и QR-кодов не реализовано — возможна только текстовая замена ручной маски.

Для сохранённого ранее документа откройте **«Защита данных»** в меню документа. Новые AI-действия потребуют подготовку и подтверждение очищенных страниц. Для старого проекта без данных предварительной подготовки страницы пересоздаются локально из сохранённого исходника, без AI и изменения текста. Существующие тексты проходят дополнительную локальную проверку; они не заменяются автоматически при подготовке масок. Изменение исходника или поворотов аннулирует прежнее разрешение на AI-анализ. Повторное распознавание после изменения поворотов требует подготовки новой копии через «Защита данных».

В защищённом режиме отключены облачные embeddings и автоматические подсказки/подстановка БЗ внутри документов. Саму БЗ можно редактировать и искать локально; её данные не добавляются в AI-запрос после подтверждения документа. Описания этих возможностей ниже относятся к обычному режиму без обязательной защиты.

Профили: `en`, `de`, `fr`, `es`, `it`, `pt`. Для каждого нужны установленные OCR-данные и NER-модель; отсутствующие зависимости блокируют подготовку, исходник в облако не отправляется. На текущем компьютере установлен и сквозным тестом проверен английский профиль. Для других языков требуется установка и отдельная проверка качества. Хинди, китайский и арабский автоматическим поиском пока не поддерживаются.

Однократная установка английского профиля:

```bash
.venv/bin/python -m pip install -r requirements-privacy.txt
.venv/bin/python -m spacy download en_core_web_sm
brew install tesseract
```

Модели других профилей: `de_core_news_sm`, `fr_core_news_sm`, `es_core_news_sm`, `it_core_news_sm`, `pt_core_news_sm`; данные Tesseract: `deu`, `fra`, `spa`, `ita`, `por` (macOS: `brew install tesseract-lang`). Загрузка зависимостей использует сеть; обработка документов ничего не скачивает автоматически.

Ключ приложения создаётся автоматически в `~/.local/share/icat/privacy.key`; другой путь задаётся `DOCUMENT_PRIVACY_KEY_FILE`. Храните и резервируйте ключ защищённо отдельно от документов: без него восстановление невозможно. Реестр замен и настройки зашифрованы. Оригиналы, сцены, экспорты и копии проверки всё равно конфиденциальны: маски могут пропустить данные. Локальное хранение оригинала не является шифрованием всего проекта.

Отдельный CLI остаётся доступен: `npm run privacy -- --help` — команды `init-key`, `prepare`, `approve`, `restore` для PDF/изображений и восстановления DOCX/TXT. Он не требует запуска ICAT. Проверки: `npm run test:privacy`, `npm run verify:privacy` (реальный локальный OCR/NER без Python-сети), `npm run verify:privacy:app` (сквозной HTTP-сценарий с перехваченным AI-провайдером). Все используют искусственные документы.

Основной приоритет — полнота содержимого, правильное распознавание текста, таблиц и ячеек, штампов, печатей и остальных составляющих документа, а также удобство редактирования итогового DOCX. Внешнее сходство с оригиналом вторично; дополнительные страницы перевода допустимы. Этот приоритет определяет дальнейшую переработку приложения. Описанные ниже элементы интерфейса относятся к текущей версии.

## 2. Рекомендуемый порядок работы

1. Откройте ICAT, выберите AI-провайдера и проверьте подключение.
2. Загрузите документ, проверьте ориентацию, подготовьте и подтвердите обезличенную копию, затем запустите распознавание.
3. В пространстве **«Текст и перевод»** сверьте исходник с оригиналом слева. Справа постоянно доступны две колонки: исходник и перевод.
4. Нажмите **«Перевести»**, задайте языки, инструкцию и режим БЗ. После обработки перевод появится в том же пространстве.
5. Проверьте перевод. Оба текста редактируются; исправление исходника сохраняет перевод и отмечает его как требующий обновления. Нажмите **«Обновить перевод»** для выборочного повторного перевода изменённых сегментов.
6. Нажмите **«К макету»**. При устаревшем переводе сначала откроется окно его обновления. При первом переходе приложение рассчитывает расстановку и страницы продолжения.
7. В **«Макет и выгрузка»** настройте типографику, расположение и таблицы. Перевод можно исправлять прямо на макете.
8. Нажмите **«Проверить макет»**, исправьте замечания и откройте **«Предпросмотр PDF»**. Он показывает фактически сформированный файл.
9. Скачайте DOCX или PDF из той же правой панели.

Кнопка **«Назад»** возвращает на предыдущий этап без потери сохранённых правок. Текущий этап хранится вместе со сценой и восстанавливается после повторного открытия документа.

Страницы продолжения входят в итоговый PDF/DOCX. При возврате к сверке исходника перенесённые сегменты показываются рядом со своей страницей оригинала. Для уже сохранённого старого макета новая расстановка применяется через выбор сегментов и команду **«Вернуть в исходное положение в документе»**. При повторном построении пустые автоматические страницы убираются; страницы, добавленные вручную, сохраняются. Для новых распознаваний AI также подбирает близкое семейство шрифта, цвет и межстрочный интервал; старые документы сохраняют ранее распознанное оформление.

## 3. Верхняя панель

Компактная верхняя панель имеет высоту 44 пикселя. Кнопка с тремя горизонтальными линиями размером 30 × 30 пикселей в её правой части открывает меню действий. Меню закрывается после выбора команды, клика вне него или нажатия `Esc`.

| Кнопка | Что делает |
| --- | --- |
| **Документы** | Открывает список всех рабочих и архивных документов. |
| **База знаний** | Открывает общий справочник утверждённых пар «исходный текст → перевод». |
| **AI-инструкции** | Открывает отдельное окно управления готовыми правилами перевода. Оно доступно даже без открытого документа. |
| **AI-провайдер** | Открывает выбор маршрута AI, модели и настройку ключа AITunnel. |
| **Документация** | Открывает в новой вкладке актуальные технические требования, архитектуру и критерии приёмки. |
| **Руководство** | Открывает в новой вкладке настоящее пользовательское руководство. |
| **Компоненты** | Открывает каталог согласованных UI-компонентов и используемых SVG-иконок. |
| **Отменить** | Отменяет последнее редактирующее действие только в пределах текущего этапа. Аналог `Ctrl/Cmd + Z`. |
| **Повторить** | Возвращает отменённое действие только в пределах текущего этапа. Аналог `Ctrl/Cmd + Shift + Z`. |
| **Другой документ** | Сохраняет текущую сцену и открывает выбор новых файлов. |

Команды **«Скачать DOCX»**, **«Скачать PDF»** и **«Предпросмотр PDF»** доступны в пространстве «Макет и выгрузка».

Страницы справки формируются непосредственно из актуальных Markdown-файлов проекта. После обновления руководства или технической документации достаточно перезагрузить соответствующую страницу браузера.

Все пиктограммы интерфейса берутся из локального SVG-набора и сопровождаются текстовой подсказкой или доступным названием. Страница «Компоненты» служит эталоном для уже согласованных элементов; первым в ней зафиксирован блок `SourcePreviewControls`.

## 4. Загрузка и обработка

| Элемент | Что делает |
| --- | --- |
| **Выбрать документы** | Открывает системный выбор файлов. Можно выбрать несколько документов. |
| Область загрузки | Принимает файлы перетаскиванием мышью. |
| Вкладка документа | Переключает текущий рабочий документ. Цветная точка показывает состояние обработки. |
| Кнопка с иконкой закрытия во вкладке | Закрывает вкладку в интерфейсе, но не удаляет сохранённый документ. |

После локальной подготовки открывается экран **«Проверьте ориентацию страниц»**. AI-распознавание в этот момент ещё не запущено. Для каждой страницы доступны иконки поворота на 90° влево и вправо; верхние иконки поворачивают сразу весь документ, а сброс возвращает все страницы в исходное положение. Поворот можно повторять, поэтому доступны все четыре положения. В защищённом режиме выберите язык и нажмите **«Подготовить обезличенную копию»**: страницы пересобираются с выбранной ориентацией, затем локально маскируются. Распознавание запускается только после проверки и подтверждения масок. Кнопка **«Начать распознавание»** доступна в обычном режиме без обязательной защиты. Правильный поворот особенно важен для таблиц: агент видит строки, столбцы и координаты уже в фактической ориентации страницы.

Открытые вкладки собраны у правого края строки документов. Если вкладок больше доступной ширины, список прокручивается по горизонтали.

Переключение вкладок не прерывает работу с документом и не сбрасывает его интерфейс. Для каждой вкладки отдельно сохраняются текущий этап, выделенные сегменты, история отмены, масштаб, выбранная страница и положение прокрутки. Подготовка загруженного файла продолжает показывать собственный процент и сообщение при возврате во вкладку. Во время перевода в названии вкладки появляется пометка «переводится»: можно открыть другой документ, а при возврате снова будет показан экран выполнения. Завершившийся перевод обновляет только ту вкладку, из которой он был запущен, и не переключает пользователя с открытого документа. После возвращения переведённый документ открывается в пространстве «Текст и перевод».

| Кнопка задания | Что делает |
| --- | --- |
| **Отменить обработку** | Прерывает выполняющееся AI-задание. Уже сохранённый исходник остаётся на сервере. |
| **Повторить обработку** | Повторно запускает завершившееся с ошибкой или отменённое задание без новой загрузки файла. |

Если обработка остановилась из-за соединения с AI-провайдером, сообщение уточняет причину: DNS, тайм-аут подключения, разрыв соединения или проверка HTTPS-сертификата. Это не означает, что исходный документ потерян. Восстановите соединение и нажмите **«Повторить обработку»**; сохранённые пакеты анализа используются повторно. Приложение не отправляет платный запрос повторно автоматически после сетевого сбоя.

Если DNS роутера не отвечает, администратор может задать в серверном `.env` `AI_DNS_SERVERS=1.1.1.1,1.0.0.1` и перезапустить ICAT. Настройка применяется только к внешним AI-запросам приложения; системные настройки DNS не изменяются. В корпоративной сети используйте разрешённые организацией DNS-серверы. Без этой настройки используется DNS системы. Обезличивание остаётся отдельным шагом: исправление соединения не скрывает данные документа.

Большие документы делятся сервером на пакеты страниц. Интерфейс показывает общий процент, номер текущего пакета, количество обработанных страниц и найденных сегментов.
Во время обработки экран загрузки использует нейтральный заголовок **«Готовим документ к работе»**, поскольку первым этапом является проверка распознавания, а не непосредственный перевод.

## 5. Оригинал документа

Оригинал находится слева от редактируемой области и не меняется при редактировании. При открытии документа панель оригинала по умолчанию скрыта.

Кнопки масштаба находятся поверх оригинала в правом нижнем углу области просмотра.

Слева от оригинала расположена компактная панель страниц шириной 60 пикселей. Каждая миниатюра содержит изображение исходной страницы и её номер снизу; нажатие переводит оригинал и рабочий макет к выбранной странице. Автоматические страницы продолжения, которые создаются при переносе не поместившихся сегментов, в этой панели не дублируются пустыми листами. Страницы, вручную добавленные пользователем, остаются видимыми.

| Кнопка | Что делает |
| --- | --- |
| **−** | Уменьшает оригинал. |
| **+** | Увеличивает оригинал. |
| **100%** | Показывает оригинал в масштабе 1:1. |
| Кнопка с иконкой рамки | Вписывает оригинал по ширине доступной панели. |
| Кнопка с четырьмя угловыми стрелками | Открывает оригинал поверх приложения в полноэкранном просмотре. В нём доступны переход между страницами, отдельный масштаб, режим 100% и вписывание страницы. `Esc` или крестик закрывают просмотр. |
| Кнопка с иконкой листа-макета | Сворачивает или возвращает оригинал, освобождая место для редактора. Активный вид кнопки означает, что оригинал показан; подсказка сообщает текущее действие. |
| Перетаскивание страницы левой кнопкой мыши | Перемещает увеличенный оригинал по горизонтали и вертикали внутри области просмотра. |

`Ctrl/Cmd + колесо мыши` над оригиналом изменяет его масштаб независимо от рабочего документа.

## 6. Рабочая область

Во всём интерфейсе используется единый тонкий скроллбар по образцу briefing-app: дорожка прозрачная, ползунок серый и скруглённый, а при наведении становится темнее. Оформление действует в рабочем холсте, боковых панелях, списках, модальных окнах, документации и других прокручиваемых областях.

Общая панель инструментов находится под вкладками документов. Индикатор показывает два рабочих пространства. Последовательность действий сохраняется: проверка исходника → перевод → проверка перевода → макет → проверка и выгрузка.

| Пространство | Что доступно |
| --- | --- |
| **1. Текст и перевод** | Закреплённый оригинал с пинами и парные редакторы исходника и перевода. После перевода появляется панель AI и БЗ. Чаты строки открываются через «Помощь AI с сегментом». |
| **2. Макет и выгрузка** | Редактирование перевода, геометрия, типографика, таблицы, проверка замечаний, предпросмотр и скачивание. |

Главная кнопка последовательно называется **«Перевести»**, **«К макету»**, **«Проверить макет»**. **«Назад»** возвращает к предыдущему шагу без повторного запуска перевода. Сохранённые документы прежнего этапа «Выгрузка» открываются в редактируемом макете.

В панели проверки нажатие на предупреждение выделяет все связанные сегменты и прокручивает макет к ним. **«Выбрать все»** принимает текущие замечания. После изменения текста, типографики, структуры или геометрии старый результат помечается как устаревший; проверку нужно повторить.

История Undo/Redo сохраняется при переходах. Отмена восстанавливает данные и выделение, оставаясь в текущем рабочем пространстве.

В пространстве текста оригинал уже встроен в страницу, поэтому отдельные переключатель оригинала и масштаб документа скрыты. Колонки исходника и перевода вместе занимают 60% рабочей области, оригинал — оставшееся место. При ширине окна до 1000 px оригинал располагается над редакторами. Масштаб оригинала независим; его пины и сквозные номера связывают сегменты с исходными областями. Отступы составляют 12 пикселей. После перевода измеряется полная высота строк; страницы не накладываются друг на друга.

Предупреждение о распознавании, если оно есть, занимает всю ширину строки над исходным сегментом и его переводом.

В каждой строке этапа «Документ» справа от номера находится иконная кнопка **«Исключить сегмент»**. Она предназначена для просветов оборотной стороны и других ошибочно распознанных областей и срабатывает с первого нажатия, даже если в этот момент редактировался текст этого же сегмента. После подтверждения сегмент не удаляется: он остаётся в списке, становится приглушённым и нередактируемым, а его пин — неактивным. Такой сегмент не участвует в переводе и экспорте. Кнопка в той же позиции меняет иконку и действие на **«Восстановить сегмент»**; после отдельного подтверждения сегмент снова становится активным и редактируемым. Отмена любого подтверждения не меняет документ.

Все действия ICAT, требующие подтверждения, используют внутреннее модальное окно приложения. Нативные системные диалоги браузера не применяются. Модальное окно показывает название действия, его последствия, кнопки подтверждения и отмены; закрытие по крестику, клику на затемнённый фон или `Esc` равнозначно отмене.

Внутри карточки оригинала доступны локальные команды уменьшения, увеличения, масштаба 100% и вписывания. Плашка этих команд не имеет тени, располагается вертикально в отдельной колонке справа от макета и не перекрывает изображение. Все кнопки в колонке имеют одинаковую ширину по кнопке «100%». Само изображение показывается без дополнительной рамки. Команды масштабируют только изображение оригинала и расположенные на нём пины. Увеличенный макет не выходит за границы карточки: его скрытая часть остаётся внутри прокручиваемой области с прозрачным фоном. Для перемещения зажмите левую кнопку мыши на свободном месте макета и потяните его в нужную сторону; во время захвата курсор меняется с ладони на сжатую ладонь. Кнопки-пины сохраняют своё обычное действие и не запускают перемещение. Список сегментов, его шрифт и ширина не масштабируются. `Ctrl/Cmd + колесо мыши` над оригиналом также меняет только этот локальный масштаб; над списком сегментов сочетание не действует.

Сегменты выводятся по страницам и внутри каждой страницы сортируются по порядку чтения, полученному при распознавании; если он недоступен, используется положение сверху вниз и слева направо. Нумерация сквозная по всему документу. Статичные бэйджи типа и уверенности распознавания не входят в редактируемый текст сегмента; номер расположен сразу справа от бэйджа уверенности. Вместо закрывающих текст прямоугольников на оригинале используются небольшие полупрозрачные цветные пины с теми же номерами. Пин ставится в центр исходной области распознавания, а если она недоступна — в центр первоначальных границ сегмента. Цвет и номер существуют только в интерфейсе и не изменяют документ. При наведении на строку соответствующий пин становится непрозрачнее, увеличивается и получает усиленную тень с мягкой фоновой подсветкой и рамкой толщиной 1 пиксель; наведение на пин по-прежнему выделяет связанную строку. Нажатие на пин прокручивает список к соответствующему редактируемому сегменту. Контейнер оригинала строится по фактическим границам изображения, а не по более высокой рабочей A4-странице, поэтому под изображением не появляется белый остаток; координаты пинов пересчитываются относительно этих границ. При наведении на оригинал под ним появляется увеличенный просмотр без пинов и следует за указателем. Его высота достигает 240 пикселей, но адаптивно уменьшается в низком окне, чтобы вертикальная панель управления оставалась полностью доступной.

Кнопка показа оригинала является частью общей `workbench-toolbar`, но занимает её левую ячейку шириной 60 пикселей непосредственно над миниатюрами страниц. Оригинал раскрывается рядом с панелью страниц слева направо и плавно сужает рабочий холст; повторное нажатие скрывает его в обратном направлении. Во время анимации оригинал проходит под непрозрачной панелью страниц и не перекрывает миниатюры. Сама панель оригинала сделана компактнее, чтобы оставлять больше места редактируемому макету.

Справа находится единая панель инструментов. До первого перевода она скрыта; после перевода показывает AI и БЗ. В макете одновременно доступны таблицы, типографика, расстановка и выгрузка. Экспорт не блокирует редактирование.

Если в макете сегмент не выбран, инструменты типографики, размеров и расстановки скрыты. Они появляются при выборе сегмента или ячейки. Дополнительное уведомление о необходимости выбрать сегмент не показывается. После выбора допустимые для текущего количества сегментов команды активируются. Кнопка **«Тестирование перед выгрузкой»** не зависит от выбора и расположена в самом низу панели после остальных инструментов.

| Кнопка | Что делает |
| --- | --- |
| **− / +** | Уменьшает или увеличивает редактируемый документ. |
| Кнопка с двумя разнонаправленными стрелками | Вписывает рабочий документ по доступной ширине. |
| **100%** | Возвращает редактируемый документ к фактическому масштабу 100%; с этого масштаба документ открывается по умолчанию. |

`Ctrl/Cmd + колесо мыши` меняет масштаб относительно позиции курсора. Масштаб влияет только на отображение и не меняет координаты экспорта.

Выпадающие меню сохраняют минимальную экранную ширину 180 px при уменьшении масштаба документа. Если места у края окна меньше, меню ограничивается доступной шириной, а длинные названия переносятся внутри пункта без горизонтальной прокрутки.

### Добавление и удаление страниц

В макете под каждым листом находятся две команды:

| Кнопка | Что делает |
| --- | --- |
| Кнопка `+` без текста | Вставляет новый лист того же формата сразу после выбранной страницы. Полное название команды доступно во всплывающей подсказке и скринридеру. Исходные изображения следующих страниц сохраняют правильную привязку. |
| Кнопка с корзиной без текста | Удаляет лист, только если на нём нет включённых в документ сегментов. Полное название и причина недоступности показаны в подсказке. В документе всегда остаётся хотя бы одна страница. |

У добавленной страницы нет изображения оригинала: слева отображается нейтральная пустая страница. Такой лист полноценно участвует в редактировании и экспорте.

## 7. Выбор и перемещение сегментов

Описанные ниже перемещение, групповое выделение и изменение геометрии доступны только в пространстве «Макет и выгрузка». После перевода клик по строке лишь задаёт один активный контекст для поиска в БЗ; группового выбора и влияния на массовый чат нет. В макете макет защищён от изменений.

- Обычный клик выбирает один сегмент.
- Заголовок инспектора размером 12 px показывает единый счётчик выбора: «Выбран 1 сегмент» или «Выбрано N сегментов» с правильной формой слова. Число выделено красным; отдельной подписи «Выделение» и дублирующего числового индикатора нет.
- `Ctrl/Cmd + клик` добавляет сегмент к текущему выделению или исключает его из выделения.
- Протягивание рамки по свободной области выделяет все пересекающиеся сегменты.
- Перетаскивание выбранного сегмента перемещает всю выделенную группу.
- Во время переноса сегмент следует за курсором по линиям сетки и не застревает у границы исходного листа. Целевая страница подсвечивается; после отпускания сегмент переносится в её систему координат. Отпускание в промежутке между листами выбирает ближайшую страницу.
- Выделение не добавляет сегменту отдельную обводку: состояние обозначают только маркеры перемещения и изменения размера, чтобы рамка не мешала точной визуальной расстановке.
- При множественном выделении сегмент в текущем фокусе обозначается синими маркерами перемещения и размера. У остальных выбранных сегментов маркеры серые и менее заметные. Пока зажат `Ctrl/Cmd`, клик по выбранному неактивному сегменту только переносит на него фокус и сохраняет группу. Повторный `Ctrl/Cmd + клик` по текущему сегменту снимает выбор только с него и возвращает фокус предыдущему активному сегменту. Начало перетаскивания или изменения размера также назначает соответствующий сегмент текущим без разрушения группы.
- Маркер перемещения всегда находится снаружи слева от сегмента, в том числе у левого края страницы. Он не перекрывает текст и может выходить за границу листа.
- Синий маркер в правом нижнем углу изменяет размер сегмента. Он всегда находится снаружи рамки, в том числе у правого и нижнего края страницы, поэтому не перекрывает содержимое.
- Размер фиксируется при отпускании кнопки мыши, в том числе если браузер завершил захват указателя вне самого маркера. `Esc` по-прежнему отменяет незавершённое изменение.
- Положение и размеры сегмента изменяются непосредственно на макете: перетаскиванием внешнего маркера слева и маркера размера справа снизу.
- Нажатие `Esc` отменяет незавершённое перетаскивание или изменение размера, снимает выделение, закрывает открытые окна и убирает фокус.

### Сетка

Размер сетки фиксирован и не изменяется пользователем. Крупная ячейка примерно в полтора раза больше прежней ячейки `XL`. Она делится на четыре равные части `2×2`, и каждая из этих частей ещё раз делится на четыре части `2×2`. Таким образом, одновременно видны три уровня: крупная ячейка, средняя четверть и малая внутренняя четверть. Линии крупного и среднего уровней темнее малых, поэтому структура остаётся читаемой.

На страницах любой ориентации размеры уровней сетки составляют 68, 34 и 17 px. Каждый сегмент любого типа занимает целое число малых клеток 17 × 17 px. Минимальная ширина и высота — одна малая клетка, даже если текст или изображение меньше неё. Размеры округляются вверх до нужного числа клеток, положение привязывается к ближайшим линиям сетки относительно зелёной рабочей области. Края сегмента не могут оставаться между линиями. Это правило действует для шапки, обычного текста и ячеек таблиц при открытии макета, переносе, изменении размера, вводе текста и форматировании. Сохранённые блоки со старыми дробными координатами также выравниваются по сетке.

Во время перетаскивания левый верхний угол сегмента сразу следует за ближайшими пересечениями сетки. Пока указатель переходит через границу или промежуток между страницами, захваченный сегмент продолжает двигаться поверх документа и временно не ограничивается рабочей областью исходного листа. После отпускания выбирается целевая страница, и только тогда сегмент ограничивается её последними доступными ячейками; его размеры при этом не меняются.

Если после переноса сегмент пересекается с другим сегментом, редактор размещает переносимый сегмент в ближайшем свободном месте из целых клеток рабочей области. Это правило действует для текста, ячеек таблицы, изображений, печатей, подписей и остальных типов. Размер и содержимое сохраняются. При переносе группы сохраняются расстояния между сегментами; ячейки одного фрагмента таблицы перемещаются вместе. Если на выбранной странице нет места, используется ближайшая подходящая рабочая область, а при отсутствии такой области создаётся пустая страница. Если независимая группа целиком не помещается, её сегменты размещаются отдельно; таблица сохраняет общую сетку. Уже существующие наложения исправляются при открытии макета. Изменение размера и подгонка текста также учитывают занятое место. Перенос и автоматическое размещение отменяются одним нажатием «Отменить». Фоновое обновление совпадений базы знаний не прерывает перетаскивание и не возвращает сегмент к прежним координатам.

Зелёная рамка обозначает **рабочую область документа**, а не границы найденного текста. Ориентация, которую вы проверили и подтвердили перед распознаванием, сохраняется в макете и при выгрузке: горизонтальная страница остаётся горизонтальной, портретная — портретной. Приложение не поворачивает лист и не сжимает его ради интерфейса; для просмотра используйте масштаб, «Вписать» и перемещение макета зажатой мышью. Автоматические дополнительные страницы получают ту же ориентацию и размер, что и связанный с ними исходный лист. Доступная область рассчитывается с защитными полями, после чего её правая и нижняя границы при необходимости немного сдвигаются внутрь до последней полной ячейки. Сегменты автоматически ограничиваются итоговой зелёной рамкой и не могут находиться в полях. В PDF сохраняются ориентация, координаты и свободные зоны макета; в DOCX текст и таблицы размещаются в редактируемом потоке Word.

В распознанной таблице каждая физическая ячейка становится отдельным сегментом со своей строкой, колонкой и координатами. Если AI ошибочно вернул целую строку одним текстом с табуляцией, приложение автоматически разделяет её на ячейки. Для определения ширины колонок используется корректно распознанная таблица с такой же структурой на другой странице; если такого образца нет, доступная ширина делится между колонками равномерно. Пустые ячейки не удаляются, поскольку они нужны для сохранения структуры таблицы.

Нижняя ручка зелёной рамки изменяет высоту рабочей области текущей страницы. Граница привязывается к сетке и не может пройти выше уже расположенных сегментов. После уменьшения области выравнивание относительно документа и «Расстановка» используют её новую высоту. Растяните границу вниз, чтобы снова использовать полную высоту листа; изменение можно отменить через `Ctrl/Cmd + Z`.

## 8. Форматирование текста

Если внутри активного сегмента выделен фрагмент текста, шрифт, цвет, жирность, курсив и размер применяются только к этому фрагменту. Без текстового выделения и выключенного пакетного режима форматирование применяется к последнему выбранному сегменту. Кнопка **«Выбрать все сегменты»** расположена отдельной строкой над карточкой типографики и всегда доступна, даже когда сейчас не выбран ни один сегмент. Чекбокс **«Применить ко всем выбранным»** находится внутри карточки и распространяет действие панели только на текущую группу выделения, а не на остальные сегменты документа.

Список шрифтов содержит `Arial`, `Aptos`, `Calibri`, `Cambria`, `Times New Roman`, `Georgia`, `Verdana`, `Tahoma` и `Courier New`. Цвет выбирается компактной цветовой кнопкой. Word сохраняет название выбранного семейства, но на компьютере получателя этот шрифт должен быть установлен или доступен как облачный шрифт Office; иначе Word выполнит подстановку, способную изменить переносы строк. Для наиболее переносимого результата рекомендуется Arial или Times New Roman.

| Кнопка или поле | Что делает |
| --- | --- |
| **B** | Включает или выключает полужирное начертание. |
| **I** | Включает или выключает курсив. |
| **⇤** | Выравнивает текст по левому краю. |
| **≡** | Центрирует текст внутри сегмента. |
| **⇥** | Выравнивает текст по правому краю. |
| **☰** | Выравнивает текст по ширине. |
| **Размер шрифта, px: − / размер / +** | Уменьшает или увеличивает размер выделенного текста либо выбранных сегментов с шагом 1 px. Значение от 10 до 80 можно ввести непосредственно в поле. Символ `≠` означает, что у выбранных сегментов разные размеры; подсказка раскрывает это состояние текстом. Ввод числа заменяет смешанные значения одним размером. `N/A` не используется, поскольку обычно означает «не применимо» или «нет данных», а размеры в данном случае известны, но различаются. |
| **Межстрочный интервал: − / значение / +** | Работает так же, как размер шрифта: кнопки изменяют межстрочный коэффициент с шагом 0,05 в диапазоне 0,8–3, а поле принимает прямой ввод. Шрифт расположен на отдельной строке панели; размер и интервал — ниже, рядом. При разных значениях отображается `≠`. |
| **Выбрать все сегменты / Снять выбор со всех** | Первое нажатие выделяет во всём документе все активные сегменты, для которых доступна настройка типографики. Кнопка получает активное состояние и меняет подпись; повторное нажатие снимает весь выбор. |
| **Применить ко всем выбранным** | Распространяет семейство и цвет шрифта, размер, высоту строки, жирность, курсив или выбранное выравнивание на все сегменты текущего выделения. Внутренние индивидуальные значения соответствующего свойства заменяются общим. |

В пространстве «Макет и выгрузка» правая панель **«Типографика и расстановка»** объединяет оформление, размеры, положение, выравнивание и распределение сегментов. Шрифт, размер шрифта и высота строки расположены в одном горизонтальном ряду. Цвет находится в строке «Начертание, выравнивание и цвет» рядом с кнопками жирности, курсива и выравнивания. Поля `X`, `Y`, «Ширина» и «Высота» удалены: геометрия управляется мышью непосредственно на макете.

В верхней панели этапа «Макет» кнопка **«Скрыть типы сегментов»** убирает с макета служебные подписи «Ячейка таблицы», «Штамп», «Печать» и другие типы, чтобы они не перекрывали содержимое. Иконка показывает текущее состояние: обычный глаз — подписи видны, перечёркнутый глаз — подписи скрыты. Подсказка описывает действие следующего нажатия: **«Скрыть типы сегментов»** или **«Показать типы сегментов»**. Повторное нажатие возвращает подписи. Выбранное состояние сохраняется отдельно для документа.

Команды выравнивания текста по левому краю, центру, правому краю и ширине изменяют только расположение текста внутри рамки. Они не запускают подгонку геометрии и поэтому сохраняют заданные пользователем ширину, высоту и координаты сегмента, в том числе после растяжения на рабочую область.

При первом переходе к макету за основу берутся распознанные области оригинала в уже подтверждённой ориентации. Обычный перевод переносится внутри исходной ширины колонки, ширина рамки округляется вверх по самой длинной строке до целых клеток, затем рассчитывается перенос текста и высота округляется вверх тем же способом. Центрированный текст сохраняет центр, правый — правый край с учётом привязки рамки к ближайшей линии сетки. У распознанной таблицы сохраняются пропорции исходных колонок, но их границы выравниваются по малым ячейкам сетки 17 px. Одна колонка получает одинаковые X и ширину во всех строках; правая граница одной ячейки одновременно является левой границей следующей, поэтому рамки не наслаиваются и не оставляют зазоров. Если минимальные ширины всех текстов вместе больше страницы, приложение распределяет доступное место между колонками с наибольшей потребностью, не выводя таблицу за рабочую область. Все ячейки одной строки имеют общую верхнюю границу и одинаковую высоту по самой высокой ячейке: короткие значения и пустые ячейки занимают строку целиком, поэтому визуальная сетка таблицы не распадается. После расчёта ширин текст измеряется повторно; если перевод занимает больше строк, увеличивается высота всей строки таблицы. Рост абзаца сдвигает следующие блоки его колонки; независимая колонка сохраняет положение. Ячейки одной строки таблицы переносятся вместе. Сегмент, не помещающийся внизу листа, целиком переносится на автоматически добавленную страницу той же ориентации и размера. Следующие связанные сегменты располагаются за ним. Шрифт ради размещения не уменьшается. Если один неделимый сегмент выше целой страницы или содержит слово шире страницы, приложение сообщает об этом и предлагает разделить сегмент вручную; частичная расстановка не применяется.

До ручного изменения размера обычный текстовый сегмент продолжает подгоняться по ширине и высоте текста. Ячейки таблицы изменяются общей сеткой маркерами на макете; отдельная автоматическая подгонка ячейки не применяется. Это происходит после изменения текста, перевода или типографики. Ручное изменение рамки фиксирует затронутый размер, после чего обычная подгонка его не перезаписывает. Команды размера по содержимому снимают соответствующую ручную фиксацию; растяжение на рабочую область и минимальная ширина считаются ручным выбором размера. Все сегменты всегда остаются внутри рабочей области документа.

Если переведённые сегменты не помещаются на исходной странице и приложение создаёт одну или несколько дополнительных страниц, панель оригинала не становится белой. При прокрутке макета она продолжает показывать исходную страницу, к которой относятся сегменты текущей дополнительной страницы. Если на одну страницу вручную перенесены сегменты из разных оригиналов, приоритет имеет выбранный сегмент, а без выбора показывается оригинал, к которому относится большинство сегментов. Только действительно пустая добавленная страница без связи с оригиналом показывает заглушку.

Автоматическая ширина обычного текстового сегмента ограничена распознанной областью или сохранённой шириной колонки. Короткий текст занимает минимум одну клетку; ширина округляется вверх до 17 px. Длинный текст переносится между словами на итоговой ширине, после чего высота также округляется вверх до целого числа клеток. Ячейка таблицы использует общую для всей таблицы ширину колонки, кратную 17 px, чтобы строки сохраняли единую сетку. После изменения текста или типографики на этапе макета автоматические блоки затронутой страницы перераспределяются с переносом на добавленные листы. Ручное положение остаётся фиксированным. Цвет и выравнивание сами по себе не запускают перерасчёт геометрии.

## 9. Документ

Кнопки **«Перевести»** и **«Обновить перевод»** открывают окно **«Отправить документ на перевод?»** с языками, режимом БЗ, общей инструкцией и сохранёнными инструкциями. Во время запроса редактор заменяется экраном **«Переводим документ»**. При успехе приложение возвращает пары текстов, при ошибке — текущий шаг и сообщение об ошибке.

Если документ уже переводился, приложение сравнивает текущий исходный текст и тип каждого сегмента с сохранённым состоянием последнего успешного перевода. При наличии правок акцентная кнопка **«Перевести изменённые сегменты (N)»** отправляет в AI только эти сегменты и сохраняет остальные переводы без изменений. Рядом остаётся отдельная кнопка **«Перевести заново весь документ»** для намеренного полного перезапуска. Если исходник не менялся, доступны **«Продолжить с текущим переводом»** и необязательный полный повторный перевод. Изменение исходного или целевого языка, общей инструкции, режима БЗ либо глоссария требует полного перевода: продолжение и выборочный режим в этом состоянии недоступны. Отмена закрывает окно без изменений.

Порядок чтения сегментов автоматически пересчитывается сверху вниз и слева направо при каждом сохранении сцены. Ручные координаты, размеры, тексты и переводы при этом не изменяются. Отдельной кнопки проверки структуры нет; полную проверку ошибок и предупреждений выполняет команда **«Тестирование перед выгрузкой»**.

| Кнопка | Что делает |
| --- | --- |
| **Пересегментация макета** | Красная кнопка находится в раскрываемом блоке «Повторное распознавание», отделена от команд скачивания верхней границей. Перед повторным анализом окно показывает исходные страницы и позволяет повернуть одну страницу или весь документ. В защищённом режиме повторный анализ использует только утверждённую очищенную копию; при изменении поворотов сначала подготовьте новую копию через «Защита данных». Успешный анализ полностью заменяет текущую сцену новым набором сегментов. В обычном режиме приложение заново создаёт изображения с выбранной ориентацией и отправляет их AI-провайдеру. Новые сегменты получают автоматический размер по тексту и ограничиваются рабочей областью документа. Все переводы сегментов, инструкции, ручные правки, стили и изменения расположения будут потеряны. На текущем этапе резервная версия не создаётся; «Отмена», закрытие окна и `Esc` прекращают действие без изменений. |
| **Перевести документ** | Основная акцентная кнопка переводит все переводимые сегменты документа одной операцией. Кнопка недоступна, если документ не содержит подходящих сегментов. |
| **Тестирование перед выгрузкой** | На этапе «Макет» запускает локальную проверку готовности документа без обращения к AI и без автоматического изменения сегментов. Показывает найденные ошибки и предупреждения, по которым можно перейти к связанным объектам и сразу исправить их. |

Машинный перевод всегда требует проверки переводчиком.

После перевода отдельные чекбоксы, вертикальная подпись выбора и кнопка **«Все»** не показываются. Группового выбора сегментов нет. Нажатие на карточку только делает одну строку активным контекстом для поиска совпадений в БЗ и не ограничивает массовую обработку AI.

До перевода и после него каждая строка содержит исходник и перевод. Оценка распознавания и номер находятся над исходником. Заметка агента занимает всю ширину пары; пустая заметка не показывается.

На шаге проверки исходника рядом с номером активного нетабличного сегмента находится иконка **«Разделить сегмент»**. Она открывает модальное окно с текущим исходным текстом: пустая строка отделяет одну будущую часть от другой. После подтверждения каждая непустая часть получает собственный сквозной номер, редактируемую карточку и отдельный цветной pin на оригинале. Исходная область делится между новыми сегментами в порядке чтения, поэтому связь с макетом не теряется. Перевод разделённого сегмента очищается и при следующей отправке документа переводятся новые части.

В блоке **«Помощь AI с сегментом»** находится **«Чат с AI по исходному сегменту»**. Исправление исходника этим чатом сохраняет перевод для проверки. В нём можно попросить AI исправить ошибку распознавания, разделить смешанный блок на несколько последовательных сегментов или выполнить другую задачу только с исходным текстом. Агент не переводит и не дополняет исходник; при нехватке данных он задаёт уточняющий вопрос. Ответы обеих сторон сохраняются у сегмента. Если AI выполняет разделение, результат проходит через ту же операцию геометрического деления и сразу получает новые номера и pins.

После перевода показывается пара «Распознанный исходник / Перевод». Если у сегмента есть заметка агента, она занимает всю ширину пары; пустая плашка не рендерится. Тип содержимого и уверенность распознавания выводятся нередактируемыми бейджами поверх поля оригинала. Оригинал доступен для редактирования, а поле перевода всегда остаётся редактируемым — в том числе когда машинный перевод отсутствует, исходник пуст или тип сегмента не предназначен для автоматического перевода. В такое поле можно вручную вписать любой нужный текст. Если выбранные исходный и целевой языки совпадают, приложение копирует исходный текст и его стили в перевод вместо обращения к AI; изменение перевода после этого остаётся обычной ручной правкой. Оба текста в списке всегда показаны одинаково: Arial 16 px, обычное начертание, стандартный цвет и выравнивание по левому краю. Это только представление этапа: распознанные и ранее настроенные шрифт, цвет, выравнивание и остальные параметры остаются в сцене и снова используются на этапе макета. В раскрываемом блоке «Помощь AI с сегментом» доступны чаты и первоначальный вариант перевода AI, когда он сохранён. Чат доступен для любого типа активного сегмента, включая логотип. В массовом чате модель получает все активные сегменты, самостоятельно находит те, к которым относится инструкция, и возвращает только их. Остальные тексты и служебные обозначения сохраняются без изменений и не считаются ошибкой ответа. Оба текстовых поля имеют минимальную высоту 120 px. Высота страницы списка рассчитывается по полному содержимому всех строк и не обрезается до минимальных 120 px.

## 10. Комментарии и сохраненные инструкции для AI

### Инструкция для AI

Поле «Инструкция для AI» задаёт правило для выбранных сегментов или всего документа. Его минимальная высота равна исходной высоте карточки с колонкой действий: поле можно увеличить вертикальным ресайзом, но нельзя уменьшить ниже 96 px. Примеры:

- `Все имена передавай транслитерацией.`
- `Сохраняй номера и даты без изменений.`
- `Все печати не включай в финальную сборку.`

| Кнопка | Что делает |
| --- | --- |
| **Использовать инструкцию** | Добавляет выбранную сохраненную инструкцию в поле «Инструкция для AI». Уже добавленный одинаковый текст не дублируется. |
| **Сохранить инструкцию в список инструкций** | По явному действию сохраняет текущую инструкцию в общий набор шаблонов. Кнопка недоступна, пока поле инструкции пусто или содержит только пробелы. |
| **Редактировать инструкцию** | Открывает текст выбранной готовой инструкции для изменения. |
| **Сохранить изменения** | Сохраняет новый текст шаблона на сервере. |
| **Отмена** | Закрывает редактор шаблона без сохранения. |
| **Удалить инструкцию из списка инструкций** | Удаляет выбранный шаблон после подтверждения. Уже применённые к документам комментарии не изменяются. |

Все действия в карточке «Инструкция для AI» показаны кнопками только с иконками. «Использовать инструкцию», «Сохранить инструкцию в список инструкций», «Редактировать инструкцию» и «Удалить инструкцию из списка инструкций» находятся в одной строке справа от списка сохранённых инструкций. При наведении или клавиатурном фокусе общий компонент тултипа показывает полное название команды из её доступного имени; все тултипы начинаются с заглавной буквы. Это же поведение применяется к иконным кнопкам редактора, кроме маркеров перемещения сегментов: у них нет всплывающей подсказки, чтобы она не мешала работе с ячейками. При нажатии мыши подсказка закрывается. Тултип сначала пытается разместиться по центру над кнопкой, а при нехватке места выбирает свободную сторону — снизу, справа или слева — и не выходит за границы окна.

Список сохраненных инструкций хранится на сервере и доступен в других документах. Одинаковые инструкции повторно не создаются.

### Отдельное окно «AI-инструкции»

Окно открывается одноимённой кнопкой в верхней панели и позволяет управлять всем набором независимо от документа.

| Кнопка или поле | Что делает |
| --- | --- |
| Поиск | Фильтрует список по полному тексту инструкции. |
| **＋ Новая инструкция** | Открывает пустую форму создания шаблона. |
| **Изменить** | Открывает выбранную инструкцию и позволяет изменить её текст. |
| **Сохранить инструкцию** | Создаёт новый шаблон или сохраняет изменения существующего. |
| **Отмена** | Закрывает форму без сохранения. |
| **Удалить** | Удаляет шаблон после подтверждения. Комментарии, ранее скопированные в документы, не изменяются. |
| **×** | Закрывает окно управления инструкциями. |

### Чат отдельного сегмента

Под каждой парой исходника и перевода находится простой диалог с двумя визуально различимыми сторонами: сообщения пользователя подписаны **«Вы»** и выровнены вправо, ответы подписаны **«AI-агент»** и выровнены влево. Если запрос неоднозначен, агент сначала задаёт уточняющий вопрос и не изменяет перевод до ответа. История диалога сохраняется вместе с сегментом. Список сохранённых инструкций остаётся доступен: шаблон можно добавить в поле нового сообщения или сохранить новое сообщение как шаблон.

Действия **«Использовать инструкцию»** и **«Сохранить инструкцию в список инструкций»** представлены компактными иконочными кнопками `+` и сохранения рядом со списком. Их полные названия показываются общим адаптивным тултипом; сохранение недоступно, пока поле нового сообщения пусто.

| Кнопка | Что делает |
| --- | --- |
| **Использовать инструкцию** | Добавляет выбранный готовый шаблон в новое сообщение конкретного сегмента. |
| **Сохранить инструкцию** | Сохраняет текст нового сообщения как готовый шаблон. |
| **Отправить** | Передаёт сообщение агенту для этого сегмента. Пустое сообщение или сегмент без перевода отправить нельзя. |

Если AI по явной инструкции пометил объект как исключённый, объект сохраняется в проекте, но не попадает в DOCX/PDF. Такое действие можно отменить через историю.

## 11. Правая панель инструментов

До первого перевода правая панель скрыта; затем показывает AI и БЗ. В пространстве макета инструменты и экспорт доступны одновременно. Геометрические команды без выбора скрыты; создание таблицы, проверка и скачивание доступны без выделения.

| Панель | Содержимое |
| --- | --- |
| **Перевод** | Языки, режим БЗ и инструкция в окне отправки. |
| **Сегменты** | Общий AI-чат, глоссарий и База знаний после перевода. |
| **Типографика и расстановка** | Таблица, оформление, размеры, выбор и расстановка сегментов. |
| **Выгрузка** | DOCX, PDF, предпросмотр PDF и пересегментация; отображается вместе с инструментами макета. |

Сведения конкретного сегмента после перевода находятся непосредственно в его строке, а не в правой панели. Координаты, групповой выбор и инструменты геометрии становятся доступны в пространстве «Макет и выгрузка».

В блоке **«Чат с AI по сегментам»** пользователь ведёт диалог с агентом и может отправить общую команду, например `Убрать маркировку списка`. Массовый чат всегда работает со всеми активными сегментами документа: выбора области и информационной плашки о выделении нет. Кнопка **«Отправить»** недоступна при пустом поле. AI получает только сегменты, у которых уже есть перевод или служебное обозначение; исключённые объекты не обрабатываются. Даже если большой документ технически разделён на несколько AI-пакетов, в диалоге показывается только один ответ агента, а не объединение похожих формулировок каждого пакета. При неоднозначности агент задаёт уточняющий вопрос, перевод не меняется, а следующий ответ пользователя продолжает тот же сохранённый диалог.

Все полноразмерные и компактные информационные плашки используют единый компонент **«Заметка»**. Доступны нейтральный, информационный, успешный, предупреждающий и ошибочный варианты; одинаковый смысл во всех разделах приложения имеет одинаковые цвет, рамку и типографику. Эталонные варианты показаны на странице **«Компоненты»**.

| Элемент | Назначение |
| --- | --- |
| **Тип содержимого** | Меняет тип объекта: текст, таблица, ячейка, штамп, печать, подпись, рукописный текст, логотип, изображение или неопределённый объект. |
| **ID таблицы / строка / колонка / размеры объединения** | Задаёт структурную позицию ячейки в настоящей табличной модели. |
| **Распознанный исходник** | Позволяет исправить результат распознавания. |
| **Уверенность распознавания** | Показывает оценку модели. Низкое значение требует ручной проверки по оригиналу. |
| **Перевод / обозначение** | Содержит выбранный перевод или служебное обозначение объекта. |
| **Шрифт, px / Межстрочный интервал** | Задаёт размер текста и межстрочный коэффициент выбранного объекта. |

Формат специальных объектов при переводе:

- печать — `/Печать: распознанный текст/`;
- штамп — `/Штамп: распознанный текст/`;
- подпись — `/Подпись/`.

### Работа с таблицами

Перейдите в пространство **«Макет»**: здесь ячейки редактируются на странице, а карточка **«Таблица»** открыта и доступна даже без выделения. В пространстве «Текст и перевод» редактируется текст распознанных ячеек; для изменения структуры и размещения используйте макет.

В списке **«Таблицы документа»** каждая логическая таблица показана один раз, с номерами всех её страниц. Выбор из списка выделяет все её ячейки на всех страницах. Выбор метки любой части также выделяет всю таблицу; метки имеют общий номер и подпись «часть N/M». Также можно нажать фиолетовую подпись «Таблица…» над сеткой. Затем щёлкните нужную ячейку, чтобы изменить её текст, строку или колонку. Если область распознана одним сегментом типа «Таблица», у неё ещё нет структуры ячеек: такой текст редактируется как обычный блок и не появляется в списке структурных таблиц. При новом распознавании программа проверяет результат ИИ: если таблица пришла строками с разделителями, она автоматически создаёт ячейки, включая пустые, и размещает заголовки в одну строку. Для повторяющихся таблиц с совпадающими заголовками используются пропорции правильно распознанных колонок с других страниц этого документа. Если точные ширины определить нельзя, колонки сначала одинаковые, а таблица отмечается для проверки по оригиналу; «Проверить макет» покажет замечание. При неоднозначных строках исходный текст сохраняется целиком, чтобы его можно было сверить. Уже сохранённые документы эта новая обработка автоматически не пересобирает.

Для управления существующей таблицей нажмите **правую кнопку мыши на её ячейке**. Откроется контекстное меню: вставка строк и колонок, копирование, вырезание, вставка и удаление строки, выделение строки/колонки/таблицы, объединение и разделение ячеек, подгонка сетки, перенос выделенных строк и исключение таблицы из сборки. Правый щелчок по уже выделенной ячейке сохраняет группу выделения для объединения; щелчок по другой ячейке выбирает её как место действия. Меню также открывается правой кнопкой на номере строки или `Shift + F10` на ячейке/номере строки. Кнопка «Действия с таблицей» из панели убрана. Стрелки вверх/вниз выбирают команду, `Enter` выполняет её, `Esc` закрывает меню. Щелчок вне меню или прокрутка макета также закрывают его. Сохранение документа, фоновое обновление совпадений БЗ и прокрутка правой панели не закрывают открытое меню.

Чтобы убрать весь фрагмент таблицы текущей страницы из макета и выгрузки, откройте меню любой её ячейки и выберите **«Исключить таблицу из сборки»**. Отдельная кнопка **«Исключить из сборки»** в карточке «Таблица» продолжает действовать на текущее выделение. Кнопка исключает все выделенные объекты; после щелчка по отдельной ячейке она исключит только эту ячейку. Без выделения кнопка недоступна. Действие сохраняет исходные данные и отменяется через `Ctrl/Cmd + Z`.

- **Новая таблица**: раскройте этот пункт в панели «Таблица». **Указать место на странице**: задайте 1–50 строк и 1–20 колонок, нажмите кнопку и наведите указатель на макет. Предварительная сетка показывает будущую таблицу; щелчок задаёт её верхний левый угол с привязкой к сетке. Зелёная рамка означает свободное место, красная — пересечение с содержимым или выход за рабочую область; щелчок в недопустимом месте ничего не создаёт. Начальная ширина колонки — до 102 px и уменьшается у правой границы страницы. После размещения её можно изменить маркером на макете. **«Отменить размещение»** или `Esc` завершают режим без изменений. Если места нет, добавьте пустую страницу и разместите таблицу там.
- Щёлкните ячейку: панель покажет её строку и колонку (нумерация с 1), а также размеры объединения. Размер в подписи таблицы означает число строк и колонок именно на этой странице, включая пустые строки. Тип «Таблица» у текстового сегмента сам по себе не создаёт сетку.
- Введённый текст остаётся видимым сразу при переходе в другую ячейку, в том числе в новой пустой таблице. Выходить из таблицы или ждать сохранения для этого не нужно.
- **Строка выше** вставляет пустую строку высотой 34 px перед выбранной ячейкой (перед всем объединением). Выбранная и следующие строки сдвигаются вниз; предыдущие строки остаются на месте. Команда работает и для первой строки таблицы или её фрагмента на странице. Текст и объединения сохраняются.
- **Строка ниже** вставляет пустую строку высотой 34 px сразу после выбранной ячейки (после всего объединения, если оно занимает несколько строк). Уже существующие строки ниже сдвигаются вниз, их текст сохраняется. В последней строке команда добавляет строку в конец таблицы.
- **Колонка слева** вставляет пустую колонку перед выбранной ячейкой (перед всем объединением). Выбранная и следующие колонки сдвигаются вправо; команда доступна и для первой колонки. Ширина новой колонки рассчитывается по выбранной колонке, а при нехватке места применяется то же пропорциональное перераспределение, что и для вставки справа.
- **Колонка справа** вставляет пустую колонку сразу после выбранной ячейки (после всего объединения, если оно занимает несколько колонок). Уже существующие колонки справа сдвигаются. При достаточном месте новая колонка получает ширину выбранной колонки; если места меньше, используется доступная ширина с шагом 17 px. Когда свободной ширины нет, для новой колонки выделяется минимум 17 px за счёт пропорционального сужения остальных колонок с округлением по сетке. Ни одна колонка не становится уже 17 px; текст и объединения сохраняются.
- **Перенос при вставке строки**: строки и остальные элементы ниже места вставки сдвигаются без наложений. Неуместившиеся строки целиком переходят в следующую рабочую область и сдвигают её содержимое; перенос продолжается дальше при необходимости. Если следующей страницы нет, приложение создаёт её автоматически. Если у следующей страницы неподходящий размер области, перед ней добавляется страница подходящего размера. Строки, связанные вертикальным объединением, переносятся вместе. Все продолжения сохраняют общий ID таблицы, её колонки и объединения: перенос на страницу не создаёт новую самостоятельную таблицу. Если одна строка или такое объединение больше целой области, вставка отклоняется: уменьшите размер или разделите объединение. Вставка вместе с переносом и созданием страниц отменяется одним Undo.
- **Выделить таблицу** сохраняет текущую ячейку как точку вставки строк и колонок. Если для колонки нельзя обеспечить минимальные 17 px или изменение её ширины перекрывает другой сегмент, операция отклоняется целиком без потери данных.
- **Ширина колонки / Высота строки** меняются только на макете: выделите ячейку и тяните круглый маркер справа или снизу. Шаг — 17 px. Маркер с клавиатуры изменяется стрелками: влево/вправо для колонки, вверх/вниз для строки. Предпросмотр во время перетаскивания не сохраняет промежуточные правки; отпускание применяет одно действие, `Esc` отменяет жест. При нехватке места используется запас соседних колонок или строк; панель сообщает фактически доступный размер. Поля размеров, кнопки «− / +» и ползунки из панели удалены.
- **Копировать строку / Копировать строки (N)** в контекстном меню запоминает все выбранные строки, включая исходник, перевод, оформление, границы и объединения. Для одной ячейки выбирается вся её строка; для вертикального объединения — все связанные строки. Затем нажмите правой кнопкой на ячейку в нужном месте и выберите **«Вставить строку выше»** или **«…ниже»**. Создаётся новая строка, остальные сдвигаются, прежние значения не перезаписываются. Вставленная строка выделяется, и операцию можно отменить одним `Ctrl/Cmd + Z`. Копию можно вставлять повторно и в другую таблицу с тем же количеством колонок; используются ширины таблицы назначения, высота подгоняется под скопированный текст. Копия хранится только в памяти открытого приложения и исчезает после перезагрузки страницы; системный буфер обмена не меняется. Вертикальные объединения копируются целиком вместе со связанными строками; вставка внутрь вертикального объединения назначения отклоняется — выберите место до/после объединения или разделите его.
- **Вырезать строку / Вырезать строки (N)** запоминает выбранные строки в том же буфере и сразу убирает их из таблицы. Откройте меню ячейки назначения и выберите **«Вставить строку выше»** или **«Вставить строку ниже»**. Вырезание и вставка — отдельные отменяемые действия; повторное копирование или вырезание заменяет буфер. При нехватке места вставка использует перенос на следующие страницы.
- **Удалить строку / Удалить строки (N)** удаляет выбранные строки без помещения в буфер. Вертикальные объединения удаляются целиком вместе со связанными строками. Остальные строки и элементы сдвигаются; действие отменяется одним Undo.
- **Выделить строку / Выделить колонку** в меню выделяют все ячейки соответствующей строки или колонки, включая пересекающие её объединения.

- **Выделение нескольких строк**: нажмите номер строки слева от таблицы. `Shift + щелчок` по другому номеру выделит диапазон, `Ctrl/Cmd + щелчок` добавит или уберёт отдельную строку. Это номера строк таблицы; координатные цифры рабочей области служат ориентиром. Выбранные номера становятся фиолетовыми. Вертикальные объединения автоматически включают все связанные строки, чтобы не разрывать ячейку.
- **Выделить строки отсюда до конца** в меню помогает отделить нижнюю часть объединённой таблицы: откройте меню нужной строки и выполните команду.
- **Перенести выделенные строки…**: выделите строки, откройте меню правой кнопкой на выбранном номере или ячейке и выберите команду. Затем щёлкните внутри нужной рабочей области: строки перенесутся туда как продолжение той же таблицы; в исходном фрагменте оставшиеся строки уплотнятся. Если там уже есть продолжение этой таблицы, строки вставляются перед ближайшей строкой ниже места щелчка или в конец. Чтобы вставить строки в другую таблицу, щёлкните по её ячейке: они вставятся перед ней, число колонок должно совпадать. Ширины берутся из таблицы назначения; в свободной области при необходимости сужаются пропорционально. Содержимое назначения сдвигается, переполнение переносится дальше, исходные строки не дублируются. Перенос сохраняет текст, оформление, ID ячеек и их связи с исходником/БЗ; вся операция отменяется одним Undo. Можно выбрать несколько несмежных строк одного страничного фрагмента; порядок сохраняется. Для переноса в новую область сначала добавьте пустую страницу кнопкой «+». `Esc` или «Отменить перенос строк» отменяют выбор места без изменения документа. Ошибка вставки оставляет строки в источнике и позволяет выбрать другое место.

- **Маркеры размера на ячейке**: тяните круглый синий маркер справа для ширины колонки, снизу — для высоты строки. Он выглядит так же, как маркер размера обычного сегмента, и имеет увеличенную невидимую область захвата. Во время движения видна новая геометрия всей таблицы; отпускание применяет изменение, `Esc` отменяет. Маркер можно сфокусировать клавишей `Tab` и менять размер стрелками. У объединённой ячейки маркер изменяет последнюю охваченную колонку или строку, команды меню используют выбранную ячейку.
- **Выровнять сетку по тексту** в контекстном меню убирает промежутки между строками, восстанавливает общие границы и подбирает минимальные высоты по содержимому во всех продолжениях выбранной таблицы. Более длинный текст требует большей высоты, поэтому высоты строк могут различаться. Строки располагаются вплотную без наложений; неуместившаяся часть переносится в следующую область как продолжение той же таблицы, соседнее содержимое сдвигается. Текст, оформление и объединения сохраняются, вся команда отменяется одним Undo. При открытии макета старые наложения и выход таблицы за область автоматически исправляются совместным размещением строк, без прижимания отдельных ячеек к краю страницы. Если одна неделимая строка или вертикальное объединение больше целой области, уменьшите её размер или разделите объединение. При ручном изменении размеров маркер по-прежнему ограничивается доступным местом.
- Общие кнопки размера в карточке «Сегменты» при выборе ячейки отключены: размеры таблицы меняются согласованно маркерами на макете.
- **Объединить ячейки**: выделите ячейки прямоугольной области через Ctrl / Cmd + щелчок. Тексты соединяются по порядку строк с переносами; индивидуальные inline-стили сбрасываются.
- **Разделить ячейку** возвращает объединённую область в сетку. Весь текст остаётся в верхней левой ячейке, остальные пустые.
- **Выделить таблицу** выбирает все её продолжения на всех страницах. Для типографики автоматически включается «Применить ко всем выбранным». Чтобы переместить только часть, выберите номера нужных строк и команду **«Перенести выбранные строки»**: щёлкните по свободному месту рабочей области или по строке назначения. Общий ID таблицы сохраняется. Перетаскивание многостраничного выделения одной ручкой не выполняется, чтобы не сложить страницы в одну область. При выборе одной ячейки её ручка перемещает только текущий фрагмент.

Каждая структурная операция отменяется одним Undo. Разделение ячейки обычной командой разделения текста запрещено, чтобы не создавать два сегмента с одним адресом. Удаление колонок пока не предусмотрено. В DOCX явно распознанная шапка повторяется при автоматическом переносе Word; в макете редактора копия шапки не создаётся. Для удаления строки используйте команду меню, а не исключение отдельных ячеек.

### Предпросмотр и качество экспорта

Команды выгрузки находятся вверху правой панели, над редактированием. **«Предпросмотр PDF»** сначала сохраняет сцену и собирает настоящий PDF, затем открывает его в диалоге. После правок откройте предпросмотр заново. Выгрузка сохраняет пустые ячейки, пропорции колонок и объединения. На страницах продолжения DOCX не добавляет пустые строки перед первым содержимым.

PDF использует встроенные Unicode-шрифты. Строки таблиц автоматически увеличиваются под текст; следующие блоки смещаются вниз, при необходимости добавляются страницы. Размер шрифта не уменьшается. Это расчёт копии для экспорта: координаты сохранённого макета не меняются. Итоговая пагинация может отличаться от холста. Слишком длинные значения переносятся по символам. Неразмещаемая строка, конфликт адресов или отсутствующий символ вызывают понятную ошибку вместо повреждённого файла.

DOCX содержит обычные абзацы и редактируемые таблицы Word. Строки свободно растут при вводе текста и автоматически переносятся на новые страницы. Продолжения одной таблицы остаются одной таблицей; деление на страницы может отличаться от макета и PDF. Приоритет — полнота и удобство редактирования. Печатные границы ячеек сохраняются отдельно от сетки редактора: отсутствующие или неуверенно распознанные линии автоматически не добавляются. Подозрительные места нужно сверить с оригиналом. Отображение зависит от Word и установленных шрифтов. PDF-предпросмотр не заменяет просмотр DOCX в Word. Повтор шапок таблиц и полноценный предпросмотр Word остаются в плане.

## 12. Внутренние единицы перевода

Карточка ручного управления частями сегмента временно удалена из интерфейса и будет переработана. Внутренние единицы продолжают использоваться автоматически при переводе и работе БЗ, но пользователь редактирует перевод выбранного сегмента целиком. Если старый документ содержит несколько внутренних частей, первая ручная правка общего перевода объединяет их в одну актуальную единицу без изменения геометрии сегмента.

## 13. Размеры и расположение

Рабочая область документа покрыта постоянной трёхуровневой координатной сеткой из строго одинаковых квадратов. Крупные столбцы подписаны английскими буквами `A`–`Z`, затем `AA`, `AB` и далее; крупные строки нумеруются числами от `1`. Подписи находятся снаружи верхней и левой границ рабочей области и не попадают в экспорт. Каждая крупная ячейка дважды делится на четверти `2×2`. Неполные остатки справа и снизу отбрасываются вместе с соответствующей частью рабочей области, поэтому частичных ячеек не бывает.

Каждый сегмент после завершённого действия занимает целое число малых внутренних ячеек. При загрузке, перетаскивании, ручном изменении размера, изменении текста или типографики и после команд расположения его стороны примагничиваются к линиям сетки. Поскольку линии крупного и среднего уровней входят в малую сетку, привязка одинаково работает на любом из трёх визуальных уровней. Во время захвата маркера размера рамка изменяется сразу с шагом малой клетки 17 px и сохраняет минимум одну клетку по каждой оси. После отпускания сначала окончательно рассчитывается и привязывается ширина — не меньше самого длинного неделимого фрагмента. Только затем по этой ширине пересчитывается перенос строк, определяется необходимая высота и выполняется её привязка.

### Сегменты

Карточка «Сегменты» объединяет команды изменения геометрии, объединения и исправления пересечений выбранных блоков.

| Кнопка | Что делает |
| --- | --- |
| Кнопка с горизонтальными стрелками | Подбирает ширину выбранных сегментов по содержимому. Полное название «Ширина по тексту» доступно в подсказке. |
| Кнопка с вертикальными стрелками | Подбирает высоту выбранных сегментов по содержимому. Полное название «Высота по тексту» доступно в подсказке. |
| Кнопка с четырьмя диагональными стрелками | Снимает ручную фиксацию обеих осей и возвращает постоянную автоматическую подгонку ширины и высоты по тексту. Полное название «Оба размера по тексту» доступно в подсказке. Если результат не помещается у правого или нижнего края, блок сдвигается и ограничивается рабочей областью. Для одинакового текста и оформления помогает получить одинаковые размеры блоков. |
| Кнопка с горизонтальными стрелками между границами | Растягивает каждый выбранный сегмент по ширине непрерывной свободной области сетки. Границами служат край рабочей области или ближайшие занятые ячейки. Высота сегмента при этом не уменьшается. |
| Кнопка с вертикальными стрелками между границами | Растягивает каждый выбранный сегмент по высоте непрерывной свободной области сетки и фиксирует выбранную высоту. Границами служат край рабочей области или ближайшие занятые ячейки. |
| Кнопка со сходящимися горизонтальными стрелками | Уменьшает ширину до CSS-эквивалента `min-content`: ориентиром служит самое длинное неделимое слово или фрагмент. Высота автоматически увеличивается под появившиеся переносы, поэтому содержимое остаётся полностью видимым. |
| Кнопка с двумя соединёнными скрепками | Объединяет минимум два выбранных сегмента одной страницы. Полное название «Объединить выбранные сегменты» доступно в подсказке. |
| Кнопка с расходящимися прямоугольниками | Выполняет детерминированное разнесение пересекающихся блоков без обращения к AI. Полное название «Исправить наложения» доступно в подсказке. |
| Кнопка с рамкой и возвратной стрелкой | Возвращает выбранные сегменты к структуре оригинала: сохраняет колонку и выравнивание, измеряет текущий текст и при нехватке места добавляет страницы продолжения. Другие сегменты учитываются как занятые области. Полное название — «Вернуть в исходное положение в документе». |

Во время перетаскивания выбранные сегменты сразу перемещаются по линиям сетки. Уже выровненный прямоугольник сохраняет число занятых ячеек; если его размер ещё не кратен шагу сетки, рамка расширяется наружу до целых ячеек. Геометрия соседних невыбранных объектов не меняется.

После отпускания маркера высота сегмента не может быть меньше высоты содержимого, рассчитанной по уже зафиксированной итоговой ширине. При уменьшении ширины перенос строк пересчитывается, и минимальная высота увеличивается автоматически, но итоговая рамка никогда не выходит за зелёную границу. Если текст невозможно вместить без выхода за рабочую область, тестирование перед выгрузкой сообщает о переполнении.

Все шесть команд изменения размеров в карточке «Сегменты» учитывают занятость сетки. Сначала определяется желаемый размер, затем сегмент получает ближайший к текущему положению непрерывный диапазон свободных ячеек. Невыбранные сегменты считаются препятствиями, а пространство между несколькими одновременно изменяемыми сегментами делится между ними. Команда не создаёт новых наложений; если места недостаточно, размер ограничивается доступными ячейками.

### Выравнивание выбранных относительно друг друга

Работает только для сегментов одной страницы.

Команды разделены на две подписанные группы: «Выровнять друг относительно друга, X» для горизонтального положения и «Выровнять друг относительно друга, Y» для вертикального положения.

| Кнопка | Что делает |
| --- | --- |
| **Лево / Центр X / Право** | Выравнивает выбранные блоки по горизонтальной стороне или оси общей группы. |
| **Верх / Центр Y / Низ** | Выравнивает выбранные блоки по вертикальной стороне или оси общей группы. |
Кнопки получают активный голубой фон, когда выбранные сегменты фактически соответствуют указанному выравниванию. Состояние пересчитывается после ручного перемещения, изменения размера и отмены действия.

### Выравнивание относительно док-та

Команды также разделены по осям: «Выравнивание относительно док-та, X» содержит «Лево», «Центр X» и «Право», а «Выравнивание относительно док-та, Y» — «Верх», «Центр Y» и «Низ». Они перемещают всю выбранную группу относительно рабочей области документа. Защитные поля страницы остаются недоступными для размещения.

Активная кнопка в этой группе показывает фактическое положение всей выбранной группы относительно рабочей области документа.

### Расстановка

Расстановка размещает выбранные сегменты вдоль одной оси внутри рабочей области документа:

- секция «Направление, X» содержит прямые кнопки «Лево», «Центр X», «Право», «Между», «Вокруг» и «Равномерно»;
- секция «Направление, Y» содержит прямые кнопки «Верх», «Центр Y», «Низ», «Между», «Вокруг» и «Равномерно»;
- «Между» распределяет свободное место только между сегментами, «Вокруг» оставляет равные поля вокруг них, а «Равномерно» делает одинаковыми промежутки и внешние поля;
- положение сегментов по второй оси при расстановке не меняется;
- если суммарный размер сегментов больше доступной длины выбранной оси, программа пропорционально уменьшает их размеры и текст, а затем выполняет расстановку вместо остановки с ошибкой;
- выпадающих списков и отдельной кнопки применения нет: нажатие любой кнопки расстановки выполняет действие сразу.

## 14. База знаний

База знаний хранит утверждённые переводы и глоссарии. Исходная и переводная стороны приводятся к регистру предложения независимо от регистра ввода: первая буква текста и первая буква после точки — заглавные, остальные буквы — строчные. При подстановке в документ программа адаптирует результат к регистру сегмента: строчному, с первой заглавной или полностью прописному.

### В рабочей области и инспекторе

Основное место работы с БЗ — пространство «Текст и перевод» после перевода: здесь одновременно видны исходник и перевод. Весь блок действий БЗ находится в верхней служебной строке поля перевода, на одной высоте со строкой типа и уверенности исходника. В нём доступны иконки просмотра найденных записей и добавления пары; отдельного блока действий БЗ под сегментом нет. Добавление открывает общую форму с уже заполненными текстами, языками и активным глоссарием. Можно сохранить весь сегмент или сократить оба поля до нужного слова, фразы или предложения. Сохранение выполняется только после проверки пользователем; существующая пара не перезаписывается молча. Для пустой пары добавление недоступно. Режим использования БЗ выбирается в окне отправки документа на перевод; выбор глоссария и ручной поиск похожих записей остаются в правой панели.

Служебная строка действий БЗ визуально относится к полю перевода, но технически не входит в редактируемый текст. При вводе и удалении слов браузер сохраняет каретку и фокус в текущем сегменте. Высота пересчитывается только у содержащей его страницы без временного схлопывания остальных страниц, поэтому список не скачет. После выхода из поля приложение сохраняет правку и заново проверяет совпадения с БЗ.

| Кнопка или поле | Что делает |
| --- | --- |
| **Найти похожие** | Ищет точные и векторно похожие записи для активной части выбранного сегмента. |
| **Использовать** | Подставляет выбранное предложение БЗ. |
| **Открыть БЗ** | Открывает общий редактор записей. |
| Список глоссариев | Выбирает активный глоссарий документа. |
| **＋ Новый** | Создаёт новый глоссарий. |
| **Только подсказки** | Показывает совпадения, но не подменяет самостоятельный перевод AI. |
| **БЗ имеет приоритет** | Использует точные и достаточно уверенные совпадения, сохраняя первоначальный вариант AI рядом. |
| Иконка **«Добавить пару в БЗ»** | Открывает заполненную форму для проверки и сохранения пары текущего сегмента. |

Текст, для которого найдена запись БЗ, выделяется жёлтым цветом, а на сегменте появляется красная иконка предупреждения. Отдельная надпись со счётчиком или процентом не показывается: в рабочей области выводятся только точные совпадения. Нажатие на выделенный фрагмент или иконку открывает окно с постоянным заголовком **«Найденные записи в БЗ»**. В каждой паре первым показан язык текста, который сейчас виден в сегменте, а затем — противоположная сторона записи; текст обеих колонок оформлен одинаково — 12 px и вес 500. Справа от пары находятся две иконки: открыть запись в БЗ и использовать её перевод. Исходник и перевод проверяются независимо: жёлтым выделяются только фактические точные вхождения в соответствующей колонке, с учётом границ слов, без различий регистра и пробелов. Несовпадающая строка перевода не выделяется по совпадению в исходнике. Одна запись находится в обоих направлениях: например, пара турецкий → русский доступна и для русского → турецкого документа в том же глоссарии. Если запись найдена только в переводе, её можно открыть, но действие применения неактивно («Уже содержится в переводе»), чтобы не подменить перевод обратной стороной пары. Применение доступно на втором этапе: полная пара подставляется сразу, термин внутри исходного абзаца применяется с контекстной корректировкой AI.

После создания, изменения или удаления записи БЗ открытый документ автоматически пересчитывает совпадения и сразу обновляет подсказки и жёлтые выделения — запускать повторный перевод не нужно. При каждом открытии любого сохранённого документа приложение заново сверяет его сегменты с актуальной БЗ: новые вложенные и полные совпадения получают подсветку и иконку, а обозначения удалённых записей исчезают. Если перевод ранее был применён из БЗ, его текст сохраняется как ручной результат и не удаляется. В режиме **«Только подсказки»** новый вариант не перезаписывает уже введённый перевод: пользователь применяет его явно через кнопку **«Использовать»**.

Клик по жёлтому фрагменту открывает подсказку, не включая редактирование. Как только текст сегмента или соответствующее поле инспектора получает фокус, прежние совпадения, жёлтая подсветка и иконка БЗ снимаются со всего сегмента. Новый текст не наследует оформление ранее подсвеченной фразы. Клик по пустой области документа завершает редактирование и снимает фокус. При каждой потере фокуса клиент сначала сохраняет текущее содержимое, затем заново ищет совпадения по фактическому тексту и отображает только подтверждённые точные результаты; прежние отметки из локального состояния не восстанавливаются. Похожие, но не точные варианты — например `VEKALETNAME` для изменённого `VEKALETNAMвE` — не получают жёлтую подсветку. Запрос не выполняется после каждого введённого символа.

### Общее окно Базы знаний

Окно имеет постоянную высоту и не меняет размер при появлении результатов, пустого состояния или формы записи. Список прокручивается внутри выделенной области. Поиск, фильтр глоссария и две иконные кнопки панели имеют одинаковую высоту; назначение кнопок показывается общим адаптивным тултипом.

В форме записи пользователь указывает только исходный текст, перевод и выбирает глоссарий в поле без отдельной подписи. Языки не редактируются вручную: новая пара наследует языки текущего документа, а существующая сохраняет собственное направление. Поле глоссария и снабжённые тултипами иконки отмены и сохранения расположены в одном ряду и имеют одинаковую высоту.

## 16. Тестирование перед выгрузкой

Под счётчиками расположена компактная строка «Выбрать все», которая позволяет принять или снять принятие всех замечаний. При отсутствии замечаний чекбокс недоступен. Список замечаний занимает оставшуюся высоту панели и прокручивается отдельно; сообщение об отсутствии критичных проблем отображается сразу под строкой выбора.

Кнопка «Проверить макет» находится в панели этапа «Макет». Панель тестирования выезжает справа поверх редактора. Она занимает всю высоту рабочей области под панелью инструментов и не сужает макет, панель оригинала или инспектор. Панель показывает количество ошибок, предупреждений и готовых переводов. Проверяются:

- отсутствующие переводы;
- низкая уверенность распознавания — менее 76%;
- отсутствие привязки объекта к странице;
- выход за физические границы страницы;
- размещение в защитных полях вне рабочей области;
- вероятное переполнение текстом на основе размера шрифта, ширины и высоты сегмента;
- заметные пересечения сегментов;
- пустые объекты, которые не попадут в экспорт.

Исключённые из сборки объекты в отчёт не входят. Проверка ничего не исправляет и сама по себе не запускает экспорт: это контрольный список перед скачиванием файла. Нажатие на предупреждение выбирает связанные сегменты и переносит редактор к их странице. Чекбокс без видимой подписи в карточке подтверждает, что замечание проверено и текущее состояние нужно оставить без изменений; карточка получает состояние «Принято», а замечание исключается из активных счётчиков. Снятие чекбокса возвращает его в активный список. Для доступности чекбокс имеет скрытое имя «Принять замечание». Принятие сохраняется в документе, пока участвующие в замечании сегменты не изменятся или сама проблема не исчезнет. После ручного исправления нажмите кнопку с иконкой обновления справа от счётчиков: программа сохранит сцену и заново выполнит проверку выбранного сегмента или группы. Отдельное уведомление не показывается — обновляются общий отчёт и его счётчики. Без выбранного сегмента кнопка недоступна. Строка счётчиков и кнопка имеют одинаковую высоту 44 px. Кнопка **×** закрывает панель. При переходе на этап «Выгрузка» панель проверки закрывается и сразу исключается из интерфейса.

## 19. Администрирование

Раздел **«Администрирование»** открывается из меню приложения. Поле **«Промпт чат-агента»** управляет системными правилами массового и посегментного чата во всех документах. Базовый промпт требует сначала определить смысл инструкции, самостоятельно выбрать применимые сегменты, изменить только их перевод на конечном языке и полностью игнорировать остальные. Он запрещает попутное редактирование, домыслы и изменение чисел, дат, имён, реквизитов или юридического смысла без прямого указания. Если применимых сегментов нет, агент должен честно сообщить об этом; уточняющий вопрос задаётся только при реальной неоднозначности или конфликте правил. Сохранённое изменение применяется только к следующим сообщениям и не переписывает существующую историю.

Базовый промпт требует от агента:

- отвечать чётко, понятно и по существу инструкции;
- ничего не додумывать и не добавлять отсутствующие сведения;
- изменять только сегменты на конечном языке перевода, используя исходник только как контекст;
- задавать короткий уточняющий вопрос и не применять изменения, если данных недостаточно или инструкция конфликтует с другими сегментами.

Кнопка **«Вернуть базовый промпт»** подставляет исходные правила в поле, но не применяет их до нажатия **«Сохранить»**. Пустой промпт сохранить нельзя. **«Отмена»**, закрытие окна и `Esc` отбрасывают несохранённое изменение.

## 20. Сохранение данных

- Сцена документа автоматически сохраняется после редактирования.
- Готовые документы восстанавливаются после перезагрузки страницы.
- Незавершённые задания сохраняются и возобновляются после перезапуска backend.
- База знаний хранится в PostgreSQL/pgvector, если задан `DATABASE_URL`.
- Сохраненные AI-инструкции хранятся на сервере в `data/studio/translation-instructions.json`.
- Общая история массового чата и отдельная история каждого сегмента сохраняются внутри сцены документа и восстанавливаются вместе с ним.
- Системный промпт чат-агента хранится на сервере в `data/studio/administration.json` и применяется ко всем следующим запросам массового и посегментного чата.
- Для production каталогу `data/studio` и PostgreSQL требуется постоянное хранилище и резервное копирование.

## 21. Важные ограничения

- AI может ошибаться в тексте, типе объекта и переводе. Для юридических документов обязательна проверка человеком.
- Повторный анализ исходника перестраивает сцену и может заменить ручные изменения.
- Не все сложные изображения и графические объекты пока воспроизводятся в DOCX с полной визуальной точностью.
- Низкоуверенные рекомендации AI по верстке не следует принимать без сравнения с оригиналом.
- Авторизация пользователей и разделение данных между организациями относятся к следующему production-этапу.

- Модель приложения — gpt-5.6-sol. Распознавание передаёт структуру таблицы отдельно от обычного текста, проверяет полноту адресов и пустые ячейки до сборки документа.
- В новых документах подписи типов скрыты. Перечёркнутый глаз означает, что подписи выключены; нажмите его, чтобы показать типы.
- Панель свойств стала компактнее. «Новая таблица» и «Как работать с таблицей» раскрываются по нажатию. Свойства текста и расположения появляются при выборе элемента.
- Команды повторного распознавания находятся в «Дополнительных действиях» под выгрузкой.
- DOCX предназначен для дальнейшего редактирования в Word; PDF — для просмотра фиксированного макета. При проверке DOCX откройте сам файл, а не только PDF-предпросмотр.


При выделении нескольких строк меню показывает их количество. Копирование, вырезание, удаление и перенос работают со всем диапазоном. Если строки не соседние, вставляются только выбранные строки в исходном порядке. Вставка скопированного диапазона также показывает количество строк; новая копия получает собственные идентификаторы. Чтобы отменить перенос через вырезание и вставку полностью, отмените оба действия.

Поле «Межстрочный интервал» относится к тексту внутри сегмента, а не к высоте строки таблицы. Высоту таблицы по-прежнему меняют маркером непосредственно в макете.

При экспорте соседние продолжения таблицы объединяются в одну таблицу Word. Если между ними в документе находятся обычные абзацы (например реквизиты или промежуточные итоги), они сохраняются между частями таблицы. Логическая связь продолжений в редакторе не меняется. Word подбирает ширины колонок по содержимому и автоматически переносит строки.

Голубая сетка и рамки редактора не печатаются. DOCX и PDF показывают границы, подтверждённые при распознавании, либо явно включённые вами в карточке таблицы. У созданной вручную таблицы рамки включены. Для старого документа без сведений о границах проверка макета покажет предупреждение; выполните повторное распознавание, чтобы получить эти сведения. Неизвестная граница не дорисовывается автоматически.

Кнопки номеров строк слева имеют высоту соответствующей строки, в том числе минимальные 17 px, и не перекрывают соседние номера.


### Предпросмотр после переноса строк и печатей

«Предпросмотр PDF» сохраняет расположение перенесённых строк, печатей и подписей, включая оставленные между строками промежутки. Если текст помещается в свою рамку, её положение и размер сохраняются. Если для текста нужна дополнительная высота, затронутые нижние блоки сдвигаются без наложений, а не поместившиеся строки переносятся на страницу продолжения. Печать или текст сбоку от таблицы сохраняют своё место, пока таблица их не пересекает. Сама рабочая сцена при построении PDF не меняется.

После изменения макета закройте старый предпросмотр и откройте его заново: уже открытый PDF является снимком предыдущего состояния. PDF и DOCX используют разную пагинацию — PDF проверяет расположение макета, DOCX предназначен для редактирования в Word.


### Единая таблица на нескольких страницах и рамки

Выбор таблицы по списку, метке любой части или команде «Выделить таблицу» выделяет все её продолжения. Ширина колонки и вставка колонки слева/справа применяются ко всем продолжениям одним действием; «Отменить» возвращает все части сразу. Доступная ширина учитывает рабочие области остальных частей. Выбор ячейки остаётся локальным, выбор колонки охватывает все продолжения.

В карточке «Таблица» после выбора доступны два переключателя:

- **«Рамки всей таблицы»** — включает или скрывает все границы ячеек во всех частях таблицы.
- **«Рамки выбранной строки» / «Рамки выбранных строк»** — меняет границы только выбранных строк. Общая линия с соседней строкой меняется с обеих сторон, чтобы скрытая рамка не оставалась в PDF. Вертикальные объединения учитываются целиком.

Галочка означает, что все рамки включены, пустое поле — все скрыты, минус — смешанные или нераспознанные границы. Нажатие на минус включает все рамки соответствующего выбора; следующее нажатие скрывает их. Чёрные линии в макете показывают печатные рамки; голубые служебные контуры остаются для выбора ячеек. Изменения сохраняются в документе, попадают в PDF/DOCX и отменяются одним действием.

Для переноса части выбирайте номера строк слева: Shift выбирает диапазон, Ctrl/Cmd — отдельные строки текущей части. Затем используйте контекстное меню. Когда выбрана сразу вся многостраничная таблица, команды копирования, вырезания, удаления и переноса строк недоступны до выбора конкретных строк: программа не применяет их молча только к одной странице.

Автоматическое распознавание больше не уменьшает шрифт отдельных ячеек ради исходной рамки. В макете и PDF для старых автоматически уменьшенных ячеек восстанавливается распознанный размер, а высота строки подбирается под текст. Ручной размер шрифта сохраняется. Нераспознанные границы не дорисовываются по догадке; для единых рамок включите «Рамки всей таблицы».
