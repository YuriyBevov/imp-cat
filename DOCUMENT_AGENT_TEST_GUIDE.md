# Проверка ICAT Document Agent

Статус: актуальная инструкция для ветки `experiment/codex-document-agent`  
Дата: 4 сентября 2026 года

## 1. Подготовка

Проверьте зависимости и авторизацию:

```bash
cd /Users/yuriybevov/Desktop/local-projects/icat-test
codex login status
npm run check
```

Ожидается сообщение `Logged in using ChatGPT`, 65 JavaScript-тестов и 14 Python-тестов без ошибок.

Основной режим задаётся в `.env` или используется по умолчанию:

```dotenv
DOCUMENT_ANALYSIS_MODE=codex
CODEX_DOCUMENT_MODEL=gpt-5.6-sol
CODEX_DOCUMENT_TIMEOUT_MS=900000
```

## 2. Запуск

```bash
npm start
```

Откройте [http://127.0.0.1:3100](http://127.0.0.1:3100). Под полем загрузки должно быть указано, что агент готов. Если кнопка выбора файла недоступна, сначала выполните `codex login`.

## 3. Первичный анализ

1. Загрузите PDF, скан или изображение.
2. Не закрывайте экран подготовки: единый анализ плотного четырёхстраничного документа может занимать до 15 минут.
3. После открытия редактора проверьте число страниц и сегментов.
4. Переключитесь между режимами «Макет» и «Сегменты».
5. В левой панели последовательно откройте каждую оригинальную страницу.

Проверяемый результат:

- отсутствуют пустые или потерянные страницы;
- обычный текст, таблицы, ячейки, штампы, печати, подписи и рукописные области имеют правильный тип;
- у читаемых штампов и печатей сохранён текст;
- нечитаемые подписи обозначены типом и не содержат выдуманной транскрипции;
- сегменты находятся внутри соответствующей страницы;
- исходное соотношение сторон страницы не искажено.

## 4. Работа с сегментами

Проверьте редактирование исходника и перевода, добавление пустого сегмента, разделение по курсору, объединение выбранных, исключение из сборки, изменение шрифта и выравнивания, drag/resize, групповое выделение и `Cmd/Ctrl + Z`.

Кнопка «Повторить анализ исходника» заново запускает Codex по сохранённым изображениям страниц и заменяет текущую сегментацию. Перед запуском интерфейс предупреждает о потере ручных изменений; прежний `analysis.json` сохраняется в каталоге ревизий.

## 5. Экспорт

1. Нажмите «Скачать DOCX».
2. Откройте документ в Word или LibreOffice и проверьте все страницы.
3. Нажмите «Скачать PDF» и проверьте число страниц, читаемость, наложения и выходы за границы.
4. Сегменты, помеченные как исключённые, не должны попадать ни в один формат.

## 7. Известные ограничения

- Текущий запрос анализа синхронный; вкладку нельзя закрывать до завершения.
- Координаты специальных объектов соответствуют исходнику, поэтому печать или подпись может осознанно перекрывать основной текст.
- Агентная проверка уже отредактированного макета и применение её рекомендаций ещё не реализованы.
- Автоматический перевод и векторная база знаний относятся к следующему этапу.
