Ветка: `experiment/client-requirements-v2`

## Готово

- [x] Изолирована отдельная Git-ветка; прежние Grid и ONLYOFFICE прототипы не удалены.
- [x] Реализована загрузка PDF и растровых изображений до 80 МБ.
- [x] Реализован кроссплатформенный рендер многостраничного PDF в PNG через PyMuPDF с настраиваемыми 300 DPI и ограничением памяти.
- [x] macOS Vision заменён на RapidOCR/ONNX: основной, контрастный и перекрывающийся фрагментный проходы, несколько языковых моделей, альтернативы, уверенность и координаты.
- [x] Для PDF сначала извлекается нативный текстовый слой вместе с координатами, размером, жирностью и курсивом; растровый OCR дополняет его, а не уничтожает качественный исходный текст.
- [x] Одиночные изображения без искажения вписываются в страницу A4; PDF сохраняет исходные пропорции страниц.
- [x] Введена независимая модель `DocumentScene`: страницы, объекты, тип, порядок чтения, исходный текст, перевод, геометрия и стиль.
- [x] Реализована базовая группировка OCR-строк в сегменты, защита от аномально высоких рамок и от склейки коротких заголовков с длинными абзацами.
- [x] Реализована эвристическая классификация подписей, штампов, круглых печатей и логотипов.
- [x] Добавлены создание пустого текстового сегмента, разделение по курсору и перенос выделенного текста в отдельный сегмент.
- [x] Исходная страница отображается в отдельной панели слева от рабочего листа с независимым зумом и переключением через список страниц.
- [x] Панель оригинала сделана компактнее и скрывается/возвращается без изменения документа.
- [x] Добавлены режимы «Макет» и «Сегменты»: второй выводит редактируемые сегменты последовательной колонкой с визуальным разделением исходных страниц и сохраняет общие выделение, редактирование, объединение, разделение и исключение.
- [x] Реализованы выделение, `Cmd/Ctrl + клик`, рамочное выделение и групповое перемещение.
- [x] Реализованы перенос между страницами, изменение размера и возврат исходной геометрии.
- [x] Реализованы объединение сегментов и исключение объектов из финальной сборки.
- [x] Реализованы объектные настройки шрифта, жирности, курсива, выравнивания и межстрочного интервала.
- [x] Размер, жирность и курсив можно применять к выделенному фрагменту внутри сегмента; смешанное форматирование сохраняется в сцене и в DOCX/PDF.
- [x] Реализован зум под курсором через `Cmd/Ctrl + колесо` и режим «По ширине».
- [x] Трекпад-зум переведён на непрерывный экспоненциальный шаг с объединением событий по кадрам; резкие фиксированные скачки по 10% устранены.
- [x] Добавлены регулируемая сетка 4–96 px и отключаемая привязка позиции/размера сегментов к ячейкам после завершения жеста.
- [x] Добавлены выравнивание выбранных сегментов по краям/центрам, равные интервалы и позиционирование группы относительно страницы или области содержимого.
- [x] Добавлена «Расстановка» в стиле CSS Flexbox: горизонтальный ряд/вертикальная колонка, контейнер выделения/контента/страницы, `start`, `center`, `end`, `space-between`, `space-around`, `space-evenly`, поперечные `start/center/end/stretch/baseline` и регулируемый интервал.
- [x] Добавлена независимая подгонка ширины, высоты либо обоих размеров сегментов по фактически отрисованному содержимому; групповая команда даёт одинаковые размеры идентичным текстам с одинаковым стилем.
- [x] Реализованы undo/redo через `Cmd/Ctrl + Z` и `Cmd/Ctrl + Shift + Z`.
- [x] Реализовано локальное сохранение документа и сцены с ревизиями и атомарной записью JSON.
- [x] Реализована локальная память переводов: точное и нечёткое совпадение, подтверждение перевода.
- [x] Реализован серверный адаптер OpenAI-совместимого API; ключ не передаётся в браузер.
- [x] При отсутствии API сохранён полноценный ручной маршрут и автоматическая подстановка из локальной БЗ.
- [x] Реализована команда локального анализа порядка чтения.
- [x] Реализована отдельная проверка OCR: локальные правила находят низкую уверенность, альтернативы Vision, склейки, смешение алфавитов и контекстные ошибки; все результаты выводятся списком рекомендаций.
- [x] Агент проверки получает соседние сегменты и исправляет орфографические/смысловые ошибки без перевода исходника; правки применяются только после подтверждения редактора.
- [x] Добавлен выключенный по умолчанию мультимодальный режим: AITunnel или другой OpenAI-совместимый провайдер проверяет каждую страницу после локального OCR, добавляет пропущенные строки, уточняет координаты, отмечает подписи/печати/штампы и применяет только уверенные точные исправления. Удаление ложных OCR-фрагментов требует повышенной уверенности и сохраняется в диагностике.
- [x] Сегменты больше не обрезают распознанный текст: содержимое показывается полностью, а недостаточная высота рамки автоматически увеличивается.
- [x] Реализована управляемая автоверстка: расчёт высоты текста и устранение пересечений.
- [x] Реализован QA: отсутствующий перевод, низкая уверенность OCR, выход за страницу, пустой объект, переполнение и наложение.
- [x] Реализован экспорт текущей сцены в редактируемый DOCX.
- [x] Реализован экспорт текущей сцены в фиксированный PDF с кириллическими шрифтами.
- [x] Исключённые объекты пропускаются обоими экспортерами.
- [x] DOCX проходит ZIP/XML/OOXML-проверки и открывается в установленном Microsoft Word.
- [x] Пройден реальный сквозной тест на четырёхстраничном PDF Arbel.
- [x] Пройден реальный сквозной тест на изображении диплома UNH.

## Осознанно отложено после проверки базовой гипотезы

- [x] Кроссплатформенный production-адаптер OCR на ONNX без Swift и системной привязки к macOS.
- [ ] Локальная модель компьютерного зрения для автоматического обнаружения печатей, логотипов и рукописных подписей без текста.
- [ ] Табличная модель как настоящие строки/ячейки, а не набор позиционных текстовых блоков.
- [ ] Автоматическое исправление перспективы, наклона и шума фотографии перед OCR.
- [ ] Терминологические глоссарии, роли, согласование и история утверждений в PostgreSQL/pgvector.
- [ ] Защищённая авторизация, проекты, пользователи, фоновые очереди и объектное хранилище.
- [ ] Потоковая индикация этапов обработки и отмена длительной задачи.
- [ ] Автоматическая визуальная оценка готового результата относительно исходника.
- [ ] Экспорт изображений, ODT и других клиентских форматов.

Отложенные пункты не блокируют проверку полного базового сценария «загрузка → распознавание → перевод/редактура → QA → DOCX/PDF».
