# Проверка ICAT Translation Studio на реальном документе

## 1. Запуск

```bash
cd /Users/yuriybevov/Desktop/local-projects/icat-test
npm install
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
npm start
```

Откройте [http://127.0.0.1:3100](http://127.0.0.1:3100).

Тестовая версия использует локальные macOS Vision, PDFKit и AppKit, поэтому текущий импорт PDF/изображений запускается на macOS. По умолчанию сервер не загружает исходник во внешние сервисы.

## 2. Необязательная настройка API перевода

Без API можно пройти весь маршрут вручную и проверить локальную базу переводов. Для автоматического перевода:

```bash
cp .env.example .env
```

Заполните в `.env`:

```dotenv
TRANSLATION_API_URL=https://адрес-провайдера/v1/chat/completions
TRANSLATION_API_KEY=секретный-ключ
TRANSLATION_MODEL=имя-модели
DOCUMENT_VISION_ENABLED=false
```

Используется OpenAI-совместимый формат `chat/completions`. Ключ остаётся на сервере, браузер его не получает. При `DOCUMENT_VISION_ENABLED=false` в запрос включаются только тексты и контекст соседних сегментов. Если явно установить `true`, тот же AI-провайдер получит PNG выбранных страниц во время проверки OCR и сможет найти текст, пропущенный локальным распознаванием; модель должна поддерживать изображения.

## 3. Полный сценарий проверки

1. Перетащите PDF, PNG, JPEG, WebP, TIFF, HEIC или BMP в загрузочную область.
2. Дождитесь локального рендера страниц и OCR. Для четырёхстраничного скана это обычно занимает несколько секунд, но сложный файл может обрабатываться дольше.
3. В крайней левой колонке переключайте страницы. Рядом находится оригинал выбранной страницы, в центре — независимый редактируемый лист с сеткой и сегментами.
4. Масштабируйте оригинал его кнопками или `Cmd/Ctrl + колесо` внутри левой панели; масштаб редактора меняется отдельно.
5. Нажмите «Проверить OCR агентом». Список справа покажет локальные и агентные рекомендации: варианты OCR, склейки, подозрительные слова, смысловые несоответствия и возможные пропуски. Откройте сегмент или примените подтверждённую правку.
6. Нажмите «Проверить структуру». Агент пересчитает порядок чтения и покажет количество проблем.
7. Выберите сегмент. Справа можно исправить OCR, изменить тип (`Текст`, `Штамп`, `Круглая печать`, `Подпись`, `Логотип`), ввести перевод и точные размеры.
8. Для нескольких сегментов используйте `Cmd/Ctrl + клик` или протяните рамку по свободной части страницы. Выбранные блоки можно перемещать вместе и объединять.
9. Кнопка «Добавить пустой сегмент» создаёт новый текстовый блок. Для существующего блока поставьте курсор и нажмите «Разделить по курсору / выделению»: при выделенном тексте он будет перенесён в отдельный сегмент.
10. Чтобы изменить только часть текста, выделите её непосредственно внутри сегмента и выберите размер, жирность или курсив в верхней панели. Без текстового выделения команда применяется ко всему сегменту.
11. Выберите размер сетки в верхней панели (4–96 px). При включённой «Привязке» отпущенный после перемещения или resize сегмент фиксируется на ближайшей ячейке; во время жеста он движется плавно.
12. Для нескольких сегментов используйте блок «Расположение»: выровняйте края/центры либо распределите интервалы. Второй ряд размещает один сегмент или всю группу относительно зелёной области содержимого либо всей страницы.
13. Перемещайте сегмент за синюю ручку `⠿`; размер меняется маркером в правом нижнем углу. Сегмент можно перенести на другую страницу.
14. `Cmd/Ctrl + колесо` плавно масштабирует страницу под курсором. `Cmd/Ctrl + Z` отменяет действия, `Cmd/Ctrl + Shift + Z` возвращает их.
15. Нажмите «Перевести выбранное». При настроенном API будет применён машинный перевод; без него применятся точные совпадения из локальной БЗ, а остальные сегменты останутся для ручного ввода.
16. После проверки перевода нажмите «Подтвердить и добавить в БЗ». При повторном появлении того же исходного текста перевод подставится автоматически.
17. Для текста или служебного объекта, который OCR не обнаружил, нажмите «Добавить пустой сегмент», затем выберите тип и поместите блок в нужное место по оригиналу слева.
18. Нажмите «Исправить наложения» только для выбранных проблемных блоков либо без выделения — для всей сцены. Команда расширяет рамки под текст и разносит пересечения; результат остаётся редактируемым.
19. Нажмите «Финальная проверка». Список показывает отсутствующие переводы, низкую уверенность OCR, выход за страницу, возможное переполнение и наложения. Клик по сообщению переводит к объекту.
20. Скачайте DOCX или PDF. Исключённые объекты не попадают в итоговый файл. DOCX содержит независимые редактируемые текстовые поля, PDF фиксирует текущую верстку.

## 4. Что считать ожидаемым результатом

- панель оригинала показывает страницу прямо из загруженного PDF/изображения и не участвует в экспорте;
- текстовые рамки стоят около распознанных строк, но декоративный текст, рукопись и печати требуют проверки;
- переводчик исправляет смысл и OCR, редактор — размеры и положение крупных блоков;
- итоговый документ является чистой технической перевёрсткой, а не фотографической копией скана;
- печати и подписи по умолчанию представлены маркерами `/Штамп/`, `/Круглая печать/`, `/Подпись/`;
- DOCX открывается в Microsoft Word и остаётся редактируемым; PDF соответствует текущей сцене.

## 5. Диагностика

Полная автоматическая проверка:

```bash
npm run check
```

Проверка состояния сервера:

```bash
curl http://127.0.0.1:3100/api/studio/status
```

Если `translationProviderConfigured` равен `false`, проверьте `.env` и перезапустите `npm start`.
