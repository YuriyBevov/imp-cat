# Проверка ICAT Translation Studio на реальном документе

## 1. Запуск

```bash
cd /Users/yuriybevov/Desktop/local-projects/icat-test
npm install
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
npm start
```

Откройте [http://127.0.0.1:3100](http://127.0.0.1:3100).

Импорт использует локальные PyMuPDF и RapidOCR/ONNX и одинаково запускается на macOS, Windows и Linux. По умолчанию сервер не загружает исходник во внешние сервисы.

## 2. Необязательная настройка API перевода

Без API можно пройти весь маршрут вручную и проверить локальную базу переводов. Для автоматического перевода:

```bash
cp .env.example .env
```

Заполните в `.env`:

```dotenv
TRANSLATION_API_URL=https://api.aitunnel.ru/v1/chat/completions
TRANSLATION_API_KEY=секретный-ключ
TRANSLATION_MODEL=имя-модели-перевода
DOCUMENT_VISION_ENABLED=true
DOCUMENT_VISION_MODEL=имя-модели-с-поддержкой-image
DOCUMENT_VISION_AUTO_AUGMENT=true
DOCUMENT_VISION_MIN_CONFIDENCE=0.86
```

Используется OpenAI-совместимый формат `chat/completions`. AITunnel работает по этому контракту; ключ остаётся на сервере и не попадает в браузер. При `DOCUMENT_VISION_ENABLED=true` vision-модель получает PNG каждой страницы после локального OCR. До показа редактора она может добавить отсутствующие строки с нормализованными координатами, исправить текст/геометрию и обозначить подписи, печати, штампы и логотипы. Удаление дублирующего или ложного OCR-фрагмента принимается только при уверенности не ниже 0.93, а исходная запись сохраняется в диагностике. Остальные результаты ниже порога, без координат или поверх уже найденной строки отклоняются. Чтобы страницы никогда не уходили во внешний API, оставьте значение `false`.

## 3. Полный сценарий проверки

1. Перетащите PDF, PNG, JPEG, WebP, TIFF, HEIC или BMP в загрузочную область.
2. Дождитесь рендера и многоступенчатого OCR. Контрастный и фрагментный проходы намеренно работают дольше прежнего анализатора; сложный многостраничный скан может обрабатываться несколько минут.
3. В крайней левой колонке переключайте страницы. Рядом находится оригинал выбранной страницы, в центре — независимый редактируемый лист с сеткой и сегментами.
4. Масштабируйте оригинал его кнопками или `Cmd/Ctrl + колесо` внутри левой панели; масштаб редактора меняется отдельно. Кнопка «Скрыть оригинал» освобождает место для рабочей области и тем же переключателем возвращает панель.
5. Переключатель «Макет / Сегменты» меняет только представление рабочей сцены. «Макет» показывает координатное расположение, а «Сегменты» — последовательную колонку карточек с отступами между страницами; редактирование, множественное выделение, объединение, разделение и исключение используют те же данные.
6. Нажмите «Проверить OCR агентом». Список справа покажет локальные и агентные рекомендации: варианты OCR, склейки, подозрительные слова, смысловые несоответствия и возможные пропуски. Откройте сегмент или примените подтверждённую правку.
7. Нажмите «Проверить структуру». Агент пересчитает порядок чтения и покажет количество проблем.
8. Выберите сегмент. Справа можно исправить OCR, изменить тип (`Текст`, `Штамп`, `Круглая печать`, `Подпись`, `Логотип`), ввести перевод и точные размеры.
9. Для нескольких сегментов используйте `Cmd/Ctrl + клик` или протяните рамку по свободной части страницы. Выбранные блоки можно перемещать вместе и объединять.
10. Кнопка «Добавить пустой сегмент» создаёт новый текстовый блок. Для существующего блока поставьте курсор и нажмите «Разделить по курсору / выделению»: при выделенном тексте он будет перенесён в отдельный сегмент.
11. Чтобы изменить только часть текста, выделите её непосредственно внутри сегмента и выберите размер, жирность или курсив в верхней панели. Без текстового выделения команда применяется ко всему сегменту.
12. Выберите размер сетки в верхней панели (4–96 px). При включённой «Привязке» отпущенный после перемещения или resize сегмент фиксируется на ближайшей ячейке; во время жеста он движется плавно.
13. Для нескольких сегментов используйте блок «Расположение»: выровняйте края/центры либо распределите интервалы. Второй ряд размещает один сегмент или всю группу относительно зелёной области содержимого либо всей страницы. В «Расстановке» выберите ряд или колонку, контейнер, распределение по главной оси (`start/center/end/space-between/space-around/space-evenly`), поперечное выравнивание и интервал, затем нажмите «Применить расстановку».
14. Кнопки «Ширина по тексту», «Высота по тексту» и «Оба размера» подгоняют рамки выбранных сегментов по содержимому. Для одинаковых обозначений вроде `/Подпись/` сначала примените «Оба размера» ко всей группе, затем симметрично разместите её через «Расстановку».
15. Перемещайте сегмент за синюю ручку `⠿`; размер меняется маркером в правом нижнем углу. Сегмент можно перенести на другую страницу.
16. `Cmd/Ctrl + колесо` плавно масштабирует страницу под курсором. `Cmd/Ctrl + Z` отменяет действия, `Cmd/Ctrl + Shift + Z` возвращает их.
17. Нажмите «Перевести выбранное». При настроенном API будет применён машинный перевод; без него применятся точные совпадения из локальной БЗ, а остальные сегменты останутся для ручного ввода.
18. После проверки перевода нажмите «Подтвердить и добавить в БЗ». При повторном появлении того же исходного текста перевод подставится автоматически.
19. Для текста или служебного объекта, который OCR не обнаружил, нажмите «Добавить пустой сегмент», затем выберите тип и поместите блок в нужное место по оригиналу слева.
20. Нажмите «Исправить наложения» только для выбранных проблемных блоков либо без выделения — для всей сцены. Команда расширяет рамки под текст и разносит пересечения; результат остаётся редактируемым.
21. Нажмите «Финальная проверка». Список показывает отсутствующие переводы, низкую уверенность OCR, выход за страницу, возможное переполнение и наложения. Клик по сообщению переводит к объекту.
22. Скачайте DOCX или PDF. Исключённые объекты не попадают в итоговый файл. DOCX содержит независимые редактируемые текстовые поля, PDF фиксирует текущую верстку.

## 4. Что считать ожидаемым результатом

- панель оригинала показывает страницу прямо из загруженного PDF/изображения и не участвует в экспорте;
- текстовые рамки стоят около распознанных строк, но декоративный текст, рукопись и печати требуют проверки;
- переводчик исправляет смысл и OCR, редактор — размеры и положение крупных блоков;
- итоговый документ является чистой технической перевёрсткой, а не фотографической копией скана;
- печати и подписи по умолчанию представлены маркерами `/Штамп/`, `/Круглая печать/`, `/Подпись/`;
- DOCX открывается в Microsoft Word и остаётся редактируемым; PDF соответствует текущей сцене.

## 5. Диагностика

Полная автоматическая проверка:

```bash
npm run check
```

Проверка состояния сервера:

```bash
curl http://127.0.0.1:3100/api/studio/status
```

Если `translationProviderConfigured` равен `false`, проверьте `.env` и перезапустите `npm start`.
