# Проверка ICAT Translation Studio на реальном документе

## 1. Запуск

```bash
cd /Users/yuriybevov/Desktop/local-projects/icat-test
npm install
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
npm start
```

Откройте [http://127.0.0.1:3100](http://127.0.0.1:3100).

Тестовая версия использует локальные macOS Vision, PDFKit и AppKit, поэтому текущий импорт PDF/изображений запускается на macOS. Сервер не загружает исходник во внешние сервисы.

## 2. Необязательная настройка API перевода

Без API можно пройти весь маршрут вручную и проверить локальную базу переводов. Для автоматического перевода:

```bash
cp .env.example .env
```

Заполните в `.env`:

```dotenv
TRANSLATION_API_URL=https://адрес-провайдера/v1/chat/completions
TRANSLATION_API_KEY=секретный-ключ
TRANSLATION_MODEL=имя-модели
```

Используется OpenAI-совместимый формат `chat/completions`. Ключ остаётся на сервере, браузер его не получает. В запрос включаются только тексты выбранных сегментов, язык исходника и язык перевода; изображения страниц не отправляются.

## 3. Полный сценарий проверки

1. Перетащите PDF, PNG, JPEG, WebP, TIFF, HEIC или BMP в загрузочную область.
2. Дождитесь локального рендера страниц и OCR. Для четырёхстраничного скана это обычно занимает несколько секунд, но сложный файл может обрабатываться дольше.
3. Слева переключайте страницы. В центре находится точная растровая подложка исходника, поверх неё — редактируемые сегменты.
4. Кнопкой «Исходник» включайте и выключайте подложку, ползунком меняйте прозрачность.
5. Нажмите «Проверить структуру». Агент пересчитает порядок чтения и покажет количество проблем.
6. Выберите сегмент. Справа можно исправить OCR, изменить тип (`Текст`, `Штамп`, `Круглая печать`, `Подпись`, `Логотип`), ввести перевод и точные размеры.
7. Для нескольких сегментов используйте `Cmd/Ctrl + клик` или протяните рамку по свободной части страницы. Выбранные блоки можно перемещать вместе и объединять.
8. Перемещайте сегмент за синюю ручку `⠿`; размер меняется маркером в правом нижнем углу. Сегмент можно перенести на другую страницу.
9. `Cmd/Ctrl + колесо` масштабирует страницу под курсором. `Cmd/Ctrl + Z` отменяет действия, `Cmd/Ctrl + Shift + Z` возвращает их.
10. Нажмите «Перевести выбранное». При настроенном API будет применён машинный перевод; без него применятся точные совпадения из локальной БЗ, а остальные сегменты останутся для ручного ввода.
11. После проверки перевода нажмите «Подтвердить и добавить в БЗ». При повторном появлении того же исходного текста перевод подставится автоматически.
12. Для служебного объекта, который OCR не обнаружил, нажмите «Добавить служебный объект», выберите нужный тип и поместите маркер поверх места на исходнике.
13. Нажмите «Исправить наложения» только для выбранных проблемных блоков либо без выделения — для всей сцены. Команда расширяет рамки под текст и разносит пересечения; результат остаётся редактируемым.
14. Нажмите «Финальная проверка». Список показывает отсутствующие переводы, низкую уверенность OCR, выход за страницу, возможное переполнение и наложения. Клик по сообщению переводит к объекту.
15. Скачайте DOCX или PDF. Исключённые объекты не попадают в итоговый файл. DOCX содержит независимые редактируемые текстовые поля, PDF фиксирует текущую верстку.

## 4. Что считать ожидаемым результатом

- исходные страницы совпадают с загруженным PDF/изображением, потому что используются как растровая подложка;
- текстовые рамки стоят около распознанных строк, но декоративный текст, рукопись и печати требуют проверки;
- переводчик исправляет смысл и OCR, редактор — размеры и положение крупных блоков;
- итоговый документ является чистой технической перевёрсткой, а не фотографической копией скана;
- печати и подписи по умолчанию представлены маркерами `/Штамп/`, `/Круглая печать/`, `/Подпись/`;
- DOCX открывается в Microsoft Word и остаётся редактируемым; PDF соответствует текущей сцене.

## 5. Диагностика

Полная автоматическая проверка:

```bash
npm run check
```

Проверка состояния сервера:

```bash
curl http://127.0.0.1:3100/api/studio/status
```

Если `translationProviderConfigured` равен `false`, проверьте `.env` и перезапустите `npm start`.
